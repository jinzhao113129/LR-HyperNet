# fork_ai2 — 其他AI工作目录

> 这是其他AI接手后的工作目录，所有产出放这里，和豆包的工作区分开。

## 目录结构

```
fork_ai2/
├── README.md              # 本文件
├── code_changelog.md      # 代码改动记录（改了HPC上哪个文件、哪一行、为什么）
├── notes/                 # 你的笔记、分析、调研
├── scripts/               # 你写的脚本
├── progress_YYYYMMDD.md   # 定期汇报（每隔一段时间写一个）
└── feishu_update_YYYYMMDD.md  # 要更新到飞书的内容（交给豆包更新）
```

## 规则

1. **你的产出都放这里**，不要改 `docs/` 下豆包维护的文件
2. **HPC上的新实验log_dir带`_ai2`后缀**
3. **代码改动记录在code_changelog.md**
4. **飞书不要直接改**，写feishu_update_*.md交给豆包
5. **Git用dev/ai2分支**，不要直接push main
6. **每隔一段时间写progress_YYYYMMDD.md汇报**

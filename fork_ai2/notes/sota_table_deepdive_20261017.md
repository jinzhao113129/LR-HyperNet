# C 赛道（详讲——我们的直接对手）

## SECNet — 82.4%（靶子本体）

**架构机制**（我们 fork 过代码，逐层摸过）：
- 输入 10240 点事件云 (t,x,y,p)；
- 3 个 stage 递进（2048→1024→512 中心点），每层 FPS 采样 +
  K=24 邻居分组；
- 每层双路：傅里叶聚合（SFA 空间频率 + TFA 时间频率，可学习频域
  权重）+ gated fusion（conv×group_conv 门控，**官方训练版独有、
  公开代码是死参数**——复现不可能的实锤）；
- 分类头 1080→256→101（mean+max 池化拼接）；
- **两阶段**：Stage-1 单窗 + Stage-2 跨窗（3 窗特征拼 3240 维 →
  1024→1024→101 MLP，attention 加权）——82.4 是两阶段合计。

**协议**：62703 训练窗（官方 3×30ms 固定窗 + 每窗 2 增强变体）、
5226 测试窗、150ep、AdamW lr=1e-3、无预训练无蒸馏。

**数字可信度**：靶子本体。我们实测 fork 版收敛到 70.36/72.56
（单窗+投票），官方 82.4 依赖 Stage-2（我们首跑 71.81 证明这个
差距主要在聚合层与数据增强——官方训练版代码从未公开）。

**对我们的启示（四层拆解）**：
1. 单窗天花板：官方 Table 9 单窗 60.60（300ms 简化协议）——我们
   70.36 已超它 10pp，说明双曲选点方向有效；
2. Stage-2 增量：82.4 - 单窗 = 跨窗聚合的价值（官方 attention+
   拼接 vs 我们投票 71.70 / 概率最大 73.31——聚合设计有空间）；
3. 训练配方：官方 3 变体增强 + 150ep——我们的增强×3 冲刺链正是
   对齐这层；
4. 防御点：官方代码不可复现（4 提交全简化版）——我们的对比是
   "协议对齐的直接对比"（学长拍板），不声明复现。

**使用方式**：论文 Table 2 的直接对照行 + 协议分组表的 C 组锚点。

## SpikePoint — 轻量点云路线（学长的原始灵感之一）

**架构**：事件点云直接进轻量网络（远小于 SECNet 的 1.9M 参数），
rate coding 密度通道（我们 density_channel 的出处）。数字低于
SECNet 但哲学同向：**点云直连、极简通路**。

**启示**：①轻量叙事可行（效率卖点）；②密度通道已在 LRHyperNet
实现（density_channel flag）；③验证了"事件点云原生表示"这条赛道
不止 SECNet 一家。

## TTPoint / EventMamba — C 赛道近邻

**架构**：TTPoint（Transformer 式点云处理）、EventMamba（状态
空间模型×事件）。数字均在 82.4 之下。

**启示**：C 赛道竞争者画像——都还在用通用骨干套事件数据，**没有
人做"选点准则"层面的创新**（我们 G16 的空位）；EventMamba 的
时序建模与我们 K=24 邻域互补（可引）。

# B 赛道（中讲——思想可偷，协议不可比）

## EventRPG — 85.62（SNN + SLTRP 显著性增强）

**架构机制**：事件转帧表示 → SNN 骨干；核心创新 **SLTRP**：
显著性引导的数据增强——找到事件流中的显著性区域/时段，做时间
拉伸（Stretch）、局部反转（Reverse）等保语义变换。

**数字结构拆解**（重要）：85.62 中近一半功劳来自 SLTRP——
不加增强的 SNN 基线 ~78-79，增强拉到 85.62。**增强增益 ≈ 7pp**。

**对我们的启示（三层）**：
1. ✅✅ **佐证增强决策**：事件数据上增强的增益量级实测 7pp——
   我们增强×3 冲刺链的方向被这个数字直接背书；
2. ✅ **下一站弹药**：SLTRP 思想平移点云域 = 按显著性选点/加权
   （与 16 点远程选择天然互补——显著性高的远程点优先入选）；
   等我们增强链出数、若涨点明显，SLTRP 式增强是增强深化的第
   二站；
3. 📝 引用归 SNN+增强组（协议表脚注），但 Related Work 里作为
   "事件增强有效性的最强证据"引用。

## RIPE-MambaSpike —（DailyDVS 45.7，N-Caltech 未列）

**架构**：Spiking-Mamba 混合（脉冲神经元 + 状态空间扫描），
0.87M 参数。SNN 车道的效率代表。

**启示**：SSM×事件已被占——我们的差异化必须强调"点云直连 +
几何先验"（不是序列模型路线）；其参数量叙事可对比（我们 1.9M
同为轻量档）。

## LSFormer — Spiking Transformer 局部注意力

**架构**：脉冲化的 Transformer，注意力限定局部窗口降计算。
**启示**：局部性先验的社区共识（支撑我们 K=24 邻域设计）；
其局部窗口思想与我们的"局部 KNN + 远程 16 点"互补（可引作
局部/远程分工作的旁证）。

## SpikeCLR / MorphSNN

**SpikeCLR**：对比自监督 SNN（帧域）；**MorphSNN**：自适应图
扩散 SNN。
**启示（合并一条）**：两者确认"双曲 × 对比学习 × 事件"零命中、
"自适应图 × 事件"已有近邻——我们的查新定位（双曲 KNN/双曲选点
零先例）在对比这些近邻后依然成立。

# A 赛道（简讲——协议不可比，但给出可引角度）

## TMKT — 97.93 / CKD — 97.13（RGB 跨模态蒸馏）

帧化 48×48 + VGG-SNN + RGB 教师蒸馏。**唯一可偷**：蒸馏框架
（自蒸馏/EMA teacher，不用 RGB 教师也能做）——我们 EMA 已在跑，
若出口涨点可进一步升级 mean-teacher 自蒸馏（+1-2pp 文献值）。

## GEP ViT-B/16 — 96.47（DINOv2 大预训练）

224×224 帧 + ViT + 1.8M 对对比预训练。**启示**：预训练上限 96+
证明事件信息量充足——我们 71-73 的差距在模型/训练不在数据
（这句话给我们的改进空间提供信心背书）。

## BNN+PBEV — 90.58（已存原文逐条核过）

BNext 二值 + PEV6 帧 + ImageNet 预训练 + EventBind 蒸馏，**且
Section 4.3 把 8:2 验证集当 test 用**。**最有用的竟是它的诚实**：
自己 Table 1 承认"各家 split 不一致"——我们论文协议分组表直接
引这句作为分组必要性的证据；另外 val 当 test 的做法是我们
Stage-2 干净口径设计（val-selected）的反面教材。

## Chaotic Dynamics — 84.4（预训练 ResNet-34）

3:1:1 随机 split + ImageNet 预训练。表内 TORE 79.8/TOKEN 81.6
可作"帧方法无预训练天花板 ≈82"的旁证（我们 C 组的 82.4 与之
吻合——两条表示路线的天花板在同一量级，公平）。

# 总账：三句话

1. **赛道隔离**：表内 90+ 全带预训练/蒸馏（A 组）、85.62 是
   SNN+增强（B 组）——**point-based from-scratch（C 组）SECNet
   82.4 是天花板，超它 = 超整个赛道公开最优**；
2. **最大可偷**：EventRPG 的增强功劳结构（7pp 增益实测）——
   增强链方向被背书；SLTRP 显著性平移点云是第二站；
3. **协议武器**：BNN 的 split 乱象自认 + val 当 test 反面教材
   ——论文协议分组与干净口径设计的双重依据。

## 二、逐篇整理（按数字倒序）

### 1. TMKT — 97.93%（A 组最高）

- **架构**：48×48 事件帧表示 + VGG-SNN 骨干 + RGB 域混合训练
  （跨模态蒸馏：RGB 教师的知识灌入事件学生）；
- **协议**：帧化输入 + RGB 预训练，非 from-scratch；
- **对我们的启示**：
  - ⛔ 不能比（RGB 预训练）；
  - ✅ 唯一可偷师：**蒸馏框架**——不用 RGB 教师也可做自蒸馏
    （EMA teacher，我们调研已确认小数据集 +1~2pp）；
  - 📝 引用时归"RGB 跨模态组"脚注。

### 2. CKD — 97.13%

- **架构**：同 TMKT 族（48×48 VGG-SNN + RGB 蒸馏），CKD=
  cross-knowledge distillation 变体；
- **启示**：同 TMKT——蒸馏思想可平移，协议不可比。

### 3. GEP ViT-B/16 — 96.47%

- **架构**：224×224 事件帧 → ViT-B/16 骨干 + DINOv2 对比预训练
  （1.8M 对）；
- **协议**：大 RGB 基础模型路线（预训练开销巨大）；
- **对我们的启示**：
  - ⛔ 重预训练路线与"轻量 from-scratch"哲学相反；
  - ✅ 有趣的点：**ViT 帧编码 + 预训练上限 96+** 说明事件信息量
    本身充足，我们 71-73% 的差距在模型/训练不在数据。

### 4. BNN+PBEV — 90.58%（表内"最新"，2026-10）

- **架构**：BNext 二值主干 + PEV6 事件帧编码 + ImageNet 预训练 +
  EventBind 教师蒸馏（**Codex 核验：8:2 验证集当 test**）；
- **协议陷阱**（我们已存原文 2610.09873 逐条核过）：val 当 test +
  预训练 + 蒸馏三重加成；
- **对我们的启示**：
  - ⛔ 它自己 Table 1 都承认"各家 split 不一致"——**协议乱象的
    实锤证据**，我们论文的协议分组表直接引它这句；
  - ✅ 1-bit 量化思路与我们无关，但"快速事件处理"的效率叙事
    与我们轻量哲学同向（可对比参数量：我们 1.9M vs 它的 BNext）。

### 5. EventRPG — 85.62%（你之前问的"85.5"）

- **架构**：SNN 帧路线 + **SLTRP 显著性数据增强**（事件帧上的
  显著性引导增强策略）；
- **协议**：帧表示 + SNN + 增强赛道（非 point-based）；
- **对我们的启示**：
  - ✅✅ **最重要的一条**：85.62 的近一半功劳是 SLTRP 增强——
    佐证我们"所有冲刺链加增强"的决策方向正确；
  - ✅ 下一步弹药：**SLTRP 思想平移到点云域 = 按显著性选点/加权**，
    与我们的 16 点远程选择天然互补（增强链出数后若涨点明显，
    显著性增强是下一站）；
  - 📝 引用时归"SNN+增强组"。

### 6. Chaotic Dynamics — 84.4%

- **架构**：ResNet-34（ImageNet 预训练）+ 混沌理论特征；
- **协议**：3:1:1 随机 split（seed 2024）+ 预训练——又一个协议
  不可比样本；
- **启示**：它表里的 TORE 79.8 / TOKEN 81.6（帧方法）可作为
  "帧方法不带预训练的天花板 ≈ 82"的旁证。

### 7. **SECNet — 82.4%**（我们赛道标杆）

- **架构**：事件点云 (t,x,y,p) + FPS 分层 + 傅里叶聚合（SFA/TFA）
  + 门控融合，Stage-1 单窗 + Stage-2 跨窗分类器；
- **协议**：point-based from-scratch（无预训练无蒸馏），
  8709 视频 3×30ms 窗；
- **对我们的启示**（靶子画像）：
  - 我们要超的就是这个数；差距已拆解（Stage-2 首跑 71.81 vs 82.4，
    差 10.6pp = 单窗天花板 + 聚合 + 增强 + 组件四层）；
  - 它的 Stage-2 机制（3 窗拼接 3240 维 MLP）是我们正在攻的
    下一层；官方训练版代码未公开（复现不可能，共识已定论）。

### 8. RIPE-MambaSpike — 表内无 N-Caltech 数字（DailyDVS 45.7 声称 spike 组最佳）

- **架构**：Spiking-Mamba 混合（状态空间模型 + 脉冲），0.87M 参数；
- **启示**：Mamba/SSM 路线进了事件领域但走 SNN 车道——
  我们的调研已确认"纯 MLP×双曲×事件"三轴交集无人占位，
  SSM×事件已被占，差异化叙事要强调"点云直连 + 几何先验"。

### 9. LSFormer（2605.13887）

- **架构**：Spiking Transformer + 局部注意力；
- **启示**：局部注意力思想与我们 24 邻域结构同族——
  引用可说明"局部性先验"的社区共识，支撑我们 K=24 选择。

### 10. SpikeCLR（2603.16338）/ MorphSNN（2603.14285）

- **架构**：对比自监督 SNN / 自适应图扩散 SNN（少样本/图方向）；
- **启示**：SpikeCLR 是"事件×对比学习"先例（但非双曲——
  我们调研的双曲 contrastive 事件方向零命中仍成立）；
  MorphSNN 的图扩散与我们的远程选择互补叙事可引。

## 三、对"超 82.4"战略的三句话总结

1. **赛道隔离**：表内 90+ 全带预训练/蒸馏（A 组），85.62 是 SNN+
   增强（B 组）——**point-based from-scratch 组 SECNet 82.4 仍是
   天花板**，超它 = 超整个赛道公开最优；
2. **最大可偷师**：EventRPG 的增强功劳结构（增强贡献近半）——
   我们增强链方向正确；下一站 SLTRP 显著性思想平移点云；
3. **协议武器**：BNN 论文自己承认 split 乱象——论文对比表按
   协议分组是硬需求（Codex 勘误 + 我们 40 篇扫描双确认）。

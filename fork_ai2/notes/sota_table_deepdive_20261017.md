# C 赛道（详讲——我们的直接对手）

## SECNet — 82.4%（靶子本体，我们 fork 过它的全部代码）

**架构机制**（逐层摸过的完整拆解）：
- **输入层**：10240 点事件云，每点 4 通道 (t,x,y,p)，时间戳和空间
  坐标归一化到 [0,1]，极性 ±1；
- **骨干**：3 个 stage 递进（中心点 2048→1024→512），每层先用
  FPS（最远点采样）选中心点，再为每个中心点找 K=24 个最近邻组成
  局部邻域；
- **聚合层**：每层双路并联——空间频率聚合（SFA：对 24 邻居做
  空间维 FFT，可学习频域权重）+ 时间频率聚合（TFA：对 2048 个
  中心点做时间维 FFT）；
- **门控融合**：conv 支路 × sigmoid(group_conv 支路) 的逐通道
  门控——**注意：官方开源代码里 group_conv 是死参数（从未训练），
  只有官方 checkpoint 里有它的权重——这是"训练版代码从未公开"
  的实锤证据**；
- **分类头**：mean+max 双池化拼接 1080 维 → 256 → 101 三层 MLP；
- **两阶段机制**（82.4 的关键）：Stage-1 是上面的单窗模型，
  Stage-2 是独立的跨窗分类器——把同一视频的 3 个 30ms 窗特征
  （每窗 1080 维）用 attention 加权后拼接成 3240 维，再过
  1024→1024→101 的 MLP。**82.4% 是两阶段合计的数字**。

**训练协议**：62703 训练窗（8709 视频 × 3 固定窗 [35-65ms/
135-165ms/235-265ms] × 3 变体[原窗+crop+reverse_T]）、5226 测试
窗（1742 视频 × 3 窗无增强）、150 epoch、AdamW lr=1e-3、Cosine
退火、batch 32 + 梯度累积、无预训练无蒸馏。

**数字可信度**：靶子本体，但**只能逼近不能复现**——我们实测 fork
版收敛到 70.36% acc / 72.56% seq（单窗+投票），官方 82.4 依赖
Stage-2 与官方训练版的独有组件。我们首跑 Stage-2 得到 71.81%，
证明差距主要在：①单窗模型天花板（我们 70.36 vs 官方推断单窗
~72）②数据增强深度（官方 3 变体 vs 我们的配方）③跨窗聚合设计。

**对我们的启示（四层拆解）**：
1. **单窗天花板**：官方 Table 9 的 300ms 简化协议单窗 60.60%——
   我们 70.36% 已超它 10pp，双曲选点方向有效性得到量化确认；
2. **Stage-2 增量**：82.4 - 单窗 ≈ 跨窗聚合的价值（官方
   attention+拼接 vs 我们投票 71.70 / 概率最大 73.31——聚合
   设计仍有 ~9pp 的空间待开采）；
3. **训练配方**：官方 3 变体增强 + 150ep——我们的增强×3 冲刺链
   正是对齐这层；
4. **防御点**：官方代码不可复现（GitHub 4 提交全是简化版）——
   我们的对比是"协议对齐的直接对比"（学长拍板口径），论文里
   明确声明不复现、只对比。

**论文中的使用方式**：Table 2 的直接对照行 + 协议分组表的 C 组
锚点 + Related Work 里作为"点云直连路线代表"引用。

## SpikePoint — 轻量点云路线（学长指定的原始灵感之一）

**架构机制**：事件点云**不做任何帧化/体素化**，直接 (t,x,y,p)
四通道进网络。骨干极轻（远小于 SECNet 的 1.9M 参数），核心特色
是 **rate coding 密度通道**：统计每个事件所在空间体素内的事件
计数并 log1p 压缩，作为第 5 个输入通道——让嵌入层直接感知局部
激发率（同坐标连续激发=边缘/运动，孤立单发=噪声）。任务定位是
DVS Gesture 动作识别（**不做 N-Caltech101**，注意：本地文件名
标注 ICML 有误，实为 ICLR 2024）。

**对我们的启示**：
1. **轻量叙事可行**：事件领域有效率卖点（我们 1.9M 参数同档）；
2. **密度通道已落地**：我们 LRHyperNet 的 density_channel flag
   就是它的实现——若后续实验证明密度通道有效，可直接引用；
3. **赛道确认**：事件点云原生表示路线不止 SECNet 一家，我们
   不是孤军；
4. **哲学背书**："点云直连、极简通路"被它验证——是我们纯 MLP
   倾向（替换链②⑤步候选骨架）的精神源头。

**论文中的使用方式**：Related Work 点云路线段落 + 轻量设计哲学
引用。

## TTPoint — Transformer 点云近邻

**架构机制**：把 Point Transformer 的局部注意力机制移植到事件
点云——FPS 采样 + K 邻域分组后，用注意力替代 SECNet 的傅里叶
聚合做局部信息整合。数字在 82.4 之下（具体值见表内所列）。

**对我们的启示**：
1. C 赛道竞争者画像：通用骨干（Transformer）直接套事件数据，
   **没有人做"选点准则"层面的创新**——我们的 G16（六种选点
   准则对照）在这个层面是空位，查新确认；
2. 注意力聚合 vs 我们的傅里叶/双曲注意力——ha 链正在验证的
   替换方向与它同层（可引作"注意力进事件点云"的先例）。

**论文中的使用方式**：Related Work 的 C 组段落（聚合层革新线）。

## EventMamba — 状态空间模型近邻

**架构机制**：把 Mamba（状态空间序列模型）用于事件流——事件
按时间排序成序列，用选择性状态空间扫描捕获长程时序演变。
数字在 82.4 之下。

**对我们的启示**：
1. 时序建模与我们 K=24 邻域互补（它管时间维、我们管空间维+
   远程选择）——可引作"时序/空间分维度处理"的旁证；
2. 序列化路线已被占——若替换链⑤步考虑序列化骨干（PTv3 式），
   需与它明确区分（我们保留点云直连）。

**论文中的使用方式**：Related Work 序列路线段落 + 差异声明。

# B 赛道（中讲——思想可偷，协议不可比）

## EventRPG — 85.62（SNN + SLTRP 显著性增强，增益结构的金矿）

**架构机制**：两件套——
1. **SNN 骨干**：事件转帧表示（时间窗内的累积事件图），喂给
   脉冲神经网络（Spiking Neural Network，脉冲神经元+膜电位
   动力学，事件驱动的低功耗计算）；
2. **SLTRP 增强系统**（核心创新）：显著性引导的数据增强——
   先对事件流做显著性分析（运动幅度/事件密度高的区域=显著），
   然后做保语义变换：**S**tretch（时间拉伸——显著时段变速）、
   **L**ocal-reverse（局部反转——非显著区域时间翻转）、
   **TR**imming/**P**adding（裁剪/填充）。关键设计：变换避开
   显性区域，保证语义标签不变。

**数字结构拆解**（这是我们最该学的）：
- 不加增强的 SNN 基线 ≈ 78-79%；
- 加 SLTRP 后 85.62%——**增强净增益 ≈ 7pp**，占其超越
  SECNet（82.4）的全部来源。

**对我们的启示（三层，按优先级）**：
1. ✅✅ **佐证增强决策**：事件数据上增强的增益量级实测 7pp——
   我们增强×3 冲刺链（crop/reverse/polarity/jitter/dropout）
   的方向被这个数字直接背书；若我们的增强增益也达 5pp+，
   增强就是与几何组件同量级的主力弹药；
2. ✅ **下一站弹药（SLTRP 平移点云）**：显著性思想平移到点云域
   = 按事件显著性选点/加权——与 16 点远程选择天然互补
   （显著性高的远程点优先入选，噪声点降权）。G16 的 rp1_scorer
   （特征距离+空间新颖性）与"显著性"是近亲概念——若 G16
   出数后 rp1_scorer 或增强链涨点明显，SLTRP 式增强是增强
   深化的第二站；
3. 📝 **引用归组**：SNN+增强组（协议表脚注），Related Work 里
   作为"事件增强有效性的最强公开证据"引用。

**论文中的使用方式**：协议分组表 B 组 + 增强章节的增益量级
参照 + Related Work 增强段落。

## RIPE-MambaSpike — SSM×SNN 混合（DailyDVS 45.7，N-Caltech 未列）

**架构机制**：Spiking-Mamba 混合——脉冲神经元与状态空间扫描
交替堆叠，0.87M 参数。SNN 车道的效率代表（参数量与我们同档
的轻量叙事）。

**对我们的启示**：SSM×事件已被占——我们的差异化必须强调
"点云直连 + 几何先验"（不是序列模型路线）；其 0.87M 参数的
效率叙事可对比（我们 1.9M 同为轻量档）。

**论文中的使用方式**：协议分组表 B 组脚注 + 效率对比行。

## LSFormer — Spiking Transformer 局部注意力

**架构机制**：脉冲化的 Transformer，把注意力限定在局部窗口
（而非全局）以降低计算量——局部性先验与计算效率的折中设计。

**对我们的启示**：
1. 局部性先验的社区共识——支撑我们 K=24 邻域设计（局部窗口
   大小与 K 邻域同属"局部先验"家族）；
2. 局部窗口思想与我们的"局部 KNN + 远程 16 点"互补——可引作
   "局部/远程分维度处理"的旁证（它们只做了局部侧，远程侧
   是我们的创新位）。

**论文中的使用方式**：Related Work 局部性段落引用。

## SpikeCLR — 对比自监督 SNN

**架构机制**：帧域对比学习——事件帧的正负样本对构造 + InfoNCE
损失训练脉冲编码器（自监督预训练，下游微调分类）。

**对我们的启示**：确认"双曲 × 对比学习 × 事件"零命中——
SpikeCLR 是普通欧氏对比学习，我们的双曲 contrastive 方向查新
依然成立（若未来走预训练路线，双曲对比是空位）。

**论文中的使用方式**：查新声明的对照引用。

## MorphSNN — 自适应图扩散 SNN

**架构机制**：自适应图扩散——事件构图中节点连接强度自适应
学习（不同于固定 kNN 图），扩散过程捕获时空邻域的多尺度关系。

**对我们的启示**："自适应图 × 事件"已有近邻（若走图路线需
区分）；我们的 KNN+远程选择是显式双邻域设计，与单尺度自适应
图不同族——查新定位不受影响。

**论文中的使用方式**：查新声明的对照引用。

# A 赛道（简讲——协议不可比，但给出可引角度）

## TMKT — 97.93 / CKD — 97.13（RGB 跨模态蒸馏族）

**架构机制**：48×48 事件帧 + VGG-SNN 骨干 + RGB 域教师蒸馏
（TMKT 是基本框架；CKD 是 cross-knowledge 变体——跨领域知识
蒸馏的加强版）。RGB 图像分类器的软标签作为教师信号灌入事件
学生网络——本质是**借自然图像的先验知识**。

**协议**：帧化 + RGB 预训练 + 蒸馏三重加成——与"from-scratch"
根本不同赛道。

**对我们的启示**：**唯一可偷**：蒸馏框架本身——不用 RGB 教师
也能做自蒸馏（EMA teacher / mean-teacher：训练中维护的滑动
平均模型作为教师，向学生提供一致性正则）。我们 EMA 已在冲刺链
里跑，若 EMA 出口涨点明显，下一步可升级为 mean-teacher 自
蒸馏（文献 +1-2pp）——这是 A 组思想向 C 组平移的合法通道。

**论文中的使用方式**：协议分组表 A 组（脚注：RGB 蒸馏）+
蒸馏相关工作引用。

## GEP ViT-B/16 — 96.47（DINOv2 大预训练）

**架构机制**：224×224 事件帧 + ViT-B/16 骨干 + DINOv2 对比
预训练（1.8M 对大规模训练）——大基础模型路线在事件域的应用。

**对我们的启示**：预训练上限 96+ 证明**事件信息量本身充足**
——我们 71-73 的差距在模型/训练不在数据。这句话给我们的改进
空间提供信心背书：不需要换数据，把模型和配方做好就有 20+pp
的理论空间。

**论文中的使用方式**：协议分组表 A 组 + "信息量充足"论据引用。

## BNN+PBEV — 90.58（已存原文逐条核过，表内"最新"）

**架构机制**：三件套——BNext 二值主干（1-bit 量化，极致效率）
+ PEV6 事件帧编码 + EventBind 教师蒸馏；预训练用 ImageNet。

**协议陷阱**（Codex 逐条核验过，原文 2610.09873）：Section 4.3
把 EventBind 的 8:2 **验证集当 test 用**——评测协议不干净。

**对我们的启示**（它最大的价值是"诚实"）：
1. 它自己 Table 1 承认"各家 split 不一致"（"For reported
   accuracy, Train/Val sets used by authors are not
   inconsistent"）——**我们论文协议分组表的必要性直接引这句**；
2. val 当 test 的做法是我们 Stage-2 干净口径设计（val-selected
   best + last 主口径）的反面教材——两相对照强化我们的严谨
   卖点；
3. 1-bit 量化的效率叙事与我们轻量哲学同向（可对比参数量：
   我们 1.9M 全精度 vs BNext 二值）。

**论文中的使用方式**：协议分组表 A 组 + 协议乱象证据引用 +
反面教材对照。

## Chaotic Dynamics — 84.4（预训练 ResNet-34）

**架构机制**：ResNet-34（ImageNet 预训练）+ 混沌理论特征
（事件流的非线性动力学表征）。3:1:1 随机 split（seed 2024）——
非官方划分。

**对我们的启示**：它表里的 TORE 79.8 / TOKEN 81.6（帧方法
无预训练）可作"帧方法无预训练天花板 ≈ 82"的旁证——我们 C 组
的 82.4 与之吻合，**两条表示路线的天花板在同一量级**（公平
对照的证据）。

**论文中的使用方式**：协议分组表 + 帧路线天花板旁证。

# 总账：三句话

1. **赛道隔离**：表内 90+ 全带预训练/蒸馏（A 组）、85.62 是
   SNN+增强（B 组）——**point-based from-scratch（C 组）SECNet
   82.4 是天花板，超它 = 超整个赛道公开最优**；
2. **最大可偷**：EventRPG 的增强功劳结构（7pp 增益实测）——
   增强链方向被背书；SLTRP 显著性平移点云是第二站；
3. **协议武器**：BNN 的 split 乱象自认 + val 当 test 反面教材
   ——论文协议分组与干净口径设计的双重依据。

| ResNet-50 | 0.637 | 直接帧化 + ImageNet 预训练 CNN | 帧化下限参照——**预训练也只有 64%，事件帧与自然图像差异大的证据**（佐证"帧化丢信息"） |
| EventNet | 0.425 | 早期事件专用浅层网络 | 历史起点 |

**演化史叙事线**（论文 Related Work 骨架）：手工特征（HATS）→
体素（EST/EV-VGCNN）→ 图（RG-CNNs/VMV-GCN）→ 帧序列（M-LSTM/
EFV++）→ 帧+SNN（EventRPG 族）→ **点云直连（SECNet→我们）**——
我们是这条演化链的最新一环，且在"选点准则"层面是全链条的空位。

# 4DGS 迁移方案：高斯参数化事件点表示（core idea 2）

> 2026-10-24 起草。学长提"4DGS 这项技术能不能用"，评估后选定"高斯参数化"这个切入点
> （不是渲染、不是密度控制剪枝）。本文给落地方向，作为和学长/Codex 讨论的底稿。

## 1. 结论一句话

4DGS 的招牌（可微光栅化渲染）对事件分类没用；**真正能迁的是它的"高斯参数化"思想——
把点从"裸坐标"升级成"均值 + 协方差"，协方差编码了形状/方向/尺度**。迁移到事件相机 =
给每个事件点加"局部协方差形状"通道，是现有 density_channel 的升级版。

## 2. 现状（事件点表示太裸）

- 事件点 = 裸坐标 `(t,x,y,p)` 4 维，无任何局部几何信息。
- `density_channel`（lr_hypernet 里有，FECNet 还没有）加了第 5 维"标量密度"：
  空间分 bins×bins 体素 → 体素内事件计数 → log1p。这是**0 阶矩**（"有多少点"）。
- 缺的是**2 阶矩**（"点怎么分布"）：孤立噪声事件 和 密集边缘上的事件，在裸坐标和
  标量密度上可能区分不开，但"局部协方差"能区分——前者各向同性、后者各向异性。

## 3. 4DGS 高斯参数化的启发

3DGS/4DGS 把场景点表示成 `均值 μ + 协方差 Σ + 不透明度 α`。Σ 的几何意义：
- **特征值** → 尺度 / 各向异性（扁还是长）；
- **特征向量** → 方向（朝向）；
- **迹** → 散度（≈ 密度）。

这就是"标量密度"的自然升级：密度是 0 阶矩，协方差是 2 阶矩。对事件相机，各向异性
和方向对应"边缘/轮廓"这类高判别力的几何结构。

## 4. 迁移方案：给事件点加"协方差形状"通道

复用 density_channel 的体素框架（改动最小）：

1. 空间 x,y 分 bins×bins 体素（默认 32×32，同 density_bins）。
2. 每个体素算 x,y 的 2×2 协方差矩阵 Σ，提取 **3 个不变量**：
   - `迹 tr(Σ)` = 散度（≈ 密度，替代/补充标量密度）；
   - `各向异性 = (λ1-λ2)/(λ1+λ2)` ∈ [0,1]，0=各向同性、1=极端拉长（边缘）；
   - `主方向角 θ = atan2(主特征向量)`，编码朝向。
3. 每个事件点从所在体素取这 3 个标量，输入变成 `[t,x,y,p, 3 协方差特征]` = 7 维。

## 5. 接法

- 新增 flag `--covariance_channel`（或 `--gaussian_shape`），FECNet（3090 快测）+ 
  lr_hypernet（HPC 全量）都加。
- embed 输入维度 4 → 7，**不换 backbone**（FPS/KNN/频域聚合全不动），只在输入层加通道。
- 与 `--density_channel` 互斥或并存均可（并存时标量密度被迹 tr(Σ) 覆盖，二选一即可）。

## 6. 分阶段

- **阶段 1（最小验证）**：体素协方差 3 不变量（静态、可解释、复用体素框架），快测
  验证"加协方差通道 vs 不加"test acc 差多少。
- **阶段 2（可选升级）**：若阶段 1 有正反馈，升级成可学习协方差编码器（小网络从局部
  点集学"形状向量"，替代手写 3 不变量）。

## 7. 风险与诚实声明

- **最大风险：形状信息可能已被 FECNet 频域聚合隐式学到**（FPS+KNN+FFT 理论上能捕捉
  局部几何），协方差通道可能是冗余的。所以阶段 1 的快测是"证伪优先"——不加 if 没涨，
  就说明频域 backbone 已经吸收了这部分信息，不深挖。
- 数值细节：体素协方差在小样本体素（1-2 个点）下不稳定，需加 eps / 最小点数门控。

## 项目概述

- **核心问题**：事件相机输出的事件流 / 事件点云（每个事件 = (x, y, t, p) 的 4D 时空点）具有天然的层级结构（局部事件 → 运动片段 → 物体部件 → 整体对象）。欧氏空间建模这类层级结构存在几何失配（表示失真、长程依赖丢失），双曲空间（负曲率、体积指数增长）天然适合树状/层级结构。我们的想法是把"事件点云这种特殊类型的视频"与双曲空间建模关联起来。
- **为什么急**：同行已入场。EHGCN（arXiv 2504.16616，2025-04 公开，2026-07 更新 v4）与一篇在审的 ICLR 2027 论文 ECAF-GCN（我们审的稿子）都是"事件流 + 欧氏/双曲双空间 GCN"，方向高度重合。立项前必须先吃透这两篇，找到差异化的切入点。

## 当前结论（一句话版）

1. **ECAF-GCN**（ICLR 2027 审稿，匿名）：欧氏 B-spline GCN 分支 + 双曲 GCN 分支 + 跨空间多头注意力（双曲→切空间作 Q，欧氏作 K/V）。N-Caltech101 0.706 mAP / Gen1 0.435 mAP，28.5M 参数。代码未公开。
2. **EHGCN**（arXiv 2504.16616，2025-04）：更早公开的同赛道工作（DAES 事件筛选 + MRF 运动感知超图 + 欧氏-双曲 GCN，L 版加 SSM）。GitHub 仓库已建但代码尚未放出。团队持续在更新（v4 2026-07）。
3. **点云×双曲也已拥挤**：PointCHR、HyPCV-Former（点云视频）、HyperIPC、Hyperpoint 等 2024-2026 已有多篇。
4. **我们的差异空间**：纯"检测 + 双空间融合"已无 novelty 空间；需要换任务（如事件点云视频级任务：预测/生成/异常检测/跨模态）、换机理（如 Lorentzian 模型、动态曲率、与 motion 因果建模结合）、或换数据（多模态/自有数据）。

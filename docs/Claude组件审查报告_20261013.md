## 严重问题详解

### ❌ 问题1：hyperbolic_embedding 双曲部分是恒等变换（FECNet.py:494-513）

**核心**：`log_map(exp_map(x)) ≡ x`，数学上互相抵消。
- exp_map(v) 给出 Poincaré 球点 p，‖p‖ = tanh(√c‖v‖)/√c
- log_map(p) 的 scale = atanh(√c‖p‖)/(√c‖p‖) = √c‖v‖/tanh(√c‖v‖)
- 二者相乘 = 1 ⇒ 恒等

**后果**：
- 曲率参数梯度解析上恒为 0
- 之前测的 "双曲嵌入层 +1.08pp" 实际只是 `LayerNorm(x + Linear(x))` 的效果，**不是双曲空间的效果**
- 正在跑的 172142（注意力+嵌入层）中的嵌入层部分也有这个问题

**修复方案**（三选一）：
1. 去掉首尾配对的 log，在双曲空间做真正的运算（Möbius 加法/双曲距离注意力），最后一次 log 回欧氏
2. 保留结构但在双曲空间停留处用双曲距离做聚合
3. 改名为 "bottleneck residual"，不叫 hyperbolic

**附带 bug**：FECNet.py:745 硬编码 1080，应为 `self.feature_list[-1] * 2`

---

### ❌ 问题2：event_mamba_ssm 残差行重复（FECNet.py:817-818）

```python
x = x + 0.1 * x_ssm
x = x + 0.1 * x_ssm    # ← 重复行，实际加了 0.2*x_ssm
```

**后果**：之前测的 MambaSSM 47.11%（无效）实际是 0.2 权重的结果，不是声明的 0.1。修复后需重测。

**附带问题**：建了 3 个 stage 的 mamba 模块但只用 stage3，stage0/1 参数永远无梯度。

---

### ⚠️ 问题3：hyperbolic_attention 声明与实现不符（FECNet.py:797-800）

- **声明**："替换 Attention 聚合中的欧氏距离"
- **实际**：在 fft_sptaial 聚合之后**额外加残差支路** `x = x + 0.1 * hyper_attn(x,x,x)`，原始 Attention 原封不动
- 消融测的是"加双曲自平滑残差"，不是"距离度量替换"
- 距离公式少 1/√c 因子（与 lorentz_distance 不一致，但 temperature 可吸收，不影响正确性）

**好消息**：+2.36pp 的效果是真实的（残差支路有效），只是名字/文档需要统一。

## 通过组件的注意事项

- **kda**：b80 时状态矩阵 [B,N,16,16] 约 671MB，V100-16GB 必 OOM；b8 没问题
- **rp1_selector / hyperbolic_selector**：python 循环 ~2000 格，训练会变慢但功能正确
- **spike_time_enc**：与 kda 无互斥 guard（只 guard 了 time_enc vs kda），建议扩成三者互斥
- **hyperbolic_fusion**：曲率正则遍历所有含 'curvature' 的参数，多 flag 同时开时会互相影响；单开无影响

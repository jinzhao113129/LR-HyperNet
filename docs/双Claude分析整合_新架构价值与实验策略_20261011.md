# 双 Claude 分析整合：新架构价值判断与实验策略（2026-10-11）

> 来源：HPC 上两个 Claude 会话并行分析（ed69ede0 论文策略方向 + c94ff036 架构组件方向），豆包整合审查
> 核心共识：当前"新架构比基线差"的结论不成立，因为比较基准不对齐

## 两个 Claude 的核心共识

### 1. 最关键的认知纠正：38.33% vs 54.07% 根本不可比

| 维度 | 基线 54.07% | v1 38.33% |
|---|---|---|
| batch | 32 | 8 |
| epoch | 150 | 30 |
| Train acc | 99.86%（充分拟合） | 39.06%（严重欠拟合） |

**到目前为止没有一个实验能证明"新架构比基线差"**——能证明的只有"新架构在 b8/30ep 预算下能到 38%"，而基线在同预算下能到多少，从来没测过。

### 2. v3.1 epoch9 的 27.94% 不能和 v1 的 38.33% 比

v1 的 38.33% 是 30ep 终值，v3.1 才到 9/30。CosineAnnealing 下 epoch9 的 lr 还在峰值的 79%，欠拟合模型的大幅涨分恰恰发生在最后 5 个 epoch（lr→0 阶段）。**在 v3.1 跑完之前，这个比较不成立。**

### 3. 欧氏对照是生死线

两个 Claude 都认为：欧氏对照（168343，排队中）出来之前，"双曲有没有用"没有答案。
- 差 <1pp → 双曲作为主卖点判死
- 差 ≥1.5-2pp 且方向稳定 → 进入 100ep 确认

**快速判死方法**（半小时级，不用等30ep）：写 debug 脚本记录 remote_points 的范数分布和 d_hyp/d_euc 比值分布。如果比值近似常数，softmax 注意力权重几乎相同，双曲和欧氏不可能有差异，可以直接撤。

### 4. 30ep/b8 只能筛大效应，不能下"无差异"结论

- 30ep 能信的：崩溃类结果（NaN、5%冻结）、≥5pp 且从 ep15 起方向稳定的差距
- 30ep 不能信的："两个组件差不多"（组件级差异在过拟合后的泛化差距里显现，v1 train 才 39% 远没到）
- 决定性实验规格：train acc ≥95%。按 v3.1 速度（~4h/30ep），100ep≈13h、150ep≈20h，过夜可跑

## 各组件价值判断

| 组件 | 判断 | 依据 |
|---|---|---|
| **Local-Remote Grouping** | 最可能的主创新点 | 现有 point-based 方法全是纯局部 KNN/FPS，远程语义相关事件的发现与聚合是真空位，与双曲无关 |
| **时间编码（多频 sin/cos）** | 机制成立，预期增益不大 | embed 层是线性的，sin/cos 给线性层廉价接入 t 的非线性函数；但 t 是 [0,1] 单标量，展开收益有限 |
| **双曲聚合** | 先验偏弱，待欧氏对照判定 | HFECNet 旧数据双曲vs欧氏差<0.5pp；双曲用在低层事件聚合的注意力距离上，是层级先验论证最弱的位置 |
| **曲率优化三件套** | 保留但降级为稳定器 | 0 NaN 证明有效，但单独lr/L2/warmup都是工程手段，不构成论文增量 |
| **KDA 时间编码** | 已弃用 | 梯度爆炸，24步串行递推不可训 |

## 如果双曲不掉点（与欧氏打平），论文怎么写

1. **主创新点改为 Local-Remote Grouping**，标题不含 hyperbolic
2. 时间编码作为第二贡献
3. 双曲降级为消融项（"聚合几何作为设计轴"），打平本身就是发现
4. **长尾分析**是双曲翻盘的唯一机会：训练集每类 5~333 样本严重长尾，按每类样本数分桶看双曲版在稀有类上是否反超
5. **低点数消融**：512/1024/2048/8192 点下双曲 vs 欧氏，双曲容量优势在小点数下更可能显现

## 如果双曲掉点，分档处理

- 掉 ≤1点 且长尾/低点数有任一翻盘 → 保留但收窄：双曲只放在 RemoteSelector 的距离度量里（选远程点用双曲距离，聚合仍欧氏）
- 全面掉点 → 砍掉双曲聚合，最后一档试双曲分类头（backbone全欧氏，logits层用Poincaré距离分类器），再不行就彻底放弃双曲字眼

## 下一步实验优先级

### P0 — 让现有实验跑完（不要动）
1. v3.1 修复版 b8/30ep（在跑，epoch9 Test 27.94%）—— 记录终值 + train acc
2. 欧氏对照 b8/30ep（排队中）—— 论文生死线
3. 5类 sanity（排队中）—— 最优先确认通过，不过则一切结果不可解释

### P1 — 新增，本周就排（各 ~2-4h）
4. **基线（原版SECNet）b8/30ep 百度数据** —— 当前最关键的缺失对照！回答"b8/30ep预算本身值多少分"。如果基线 b8/30ep 落在 35-40%，v1 的 38.33 从来就不是"输给基线"
5. v3.1 跑完后如果 train acc 仍低（<60%），直接跑 100ep 确认

### P2 — 条件触发
6. 欧氏对照差 <1pp → 做几何诊断（d_hyp/d_euc比值）确认判死，撤双曲
7. 欧氏对照差 ≥1.5pp → 长尾分析 + 低点数消融

### 可以直接砍掉不跑的
- fixed-c vs learned-c 消融（双曲活下来才有意义）
- v2 旧版任何实验（time_enc bug已作废）
- KDA 任何后续（已弃用）

## 论文最低可接受结果

- **及格线**：主协议打平（±0.5）+ 至少一个次级维度明确赢（长尾类、低点数、参数量/GMACs、CIFAR10-DVS上涨1-2点）
- **理想线**：至少一个数据集涨1.5+点，另一个打平
- **发不了的线**：主表输给基线2-3点，可视化/理论都救不回来

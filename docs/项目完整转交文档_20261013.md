## 十一、已知坑和注意事项

### 11.1 代码/实验坑
1. **PowerShell 禁止内联 Python**——必须写 .py 文件再 scp 上去跑
2. **fish shell 不支持 bash for 循环和 heredoc**——用脚本文件
3. **ssh stdout 常被吞**——用 `> /tmp/file.txt` 重定向再 scp 回读
4. **grep 被 rg 别名替换**——用 `/usr/bin/grep` 绝对路径
5. **"b8+grad_accum4 等效b32"不成立**——BN按micro-batch=8估计，只等效梯度
6. **rp1 选点在 eval 时也是随机的**（torch.rand），测试精度有噪声 <±0.5%
7. **日志 epoch 显示 bug**：global_epoch 不自增，永远打 "Epoch 1 (N/60)"，不影响结果
8. **checkpoint 现在存 args**——换 flag 续跑会 loud fail，不会静默错配
9. **gpu02 H100 弃用**（CUBLAS 错误）
10. **V100-16GB batch=32 OOM**，只能 b8+grad_accum4

### 11.2 网络坑
1. GitHub push 需要本地代理 127.0.0.1:7897 开启
2. HPC 只能通过校园网/VPN 访问（2223端口），2222备用
3. 飞书文档更新前必须重新 fetch（用户可能手动编辑过）

### 11.3 双曲数值坑
1. atanh 边界梯度尖峰（clamp 到 1-1e-6），有三层兜底（loss有限性检查+grad norm检查+clip 5.0）
2. 曲率无上界（abs+1e-4 只保正），需盯 TensorBoard Curvature 曲线
3. exp_map 饱和风险——已加进球前尺度归一（修复E）
4. KDA 梯度爆炸——已加 self_in 防御断言（修复F），续跑中观察

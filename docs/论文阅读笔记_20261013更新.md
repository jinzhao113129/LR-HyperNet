## 零、2026-10-13 更新要点（优先于正文）

1. **组件有效性已有明确结论**（标准消融配置，基线=纯 SECNet 47.537%）：
   - ✅ 保持：傅里叶聚合（替换掉 ~10 点）、**双曲注意力 49.572%（+2.04pp，修复版确认）**
   - 🟡 待确认：双曲选点（旧 +3.32pp，修复版在跑）、RP1（旧 +0.96pp，修复版在跑）
   - ❌ 剔除：**双曲嵌入层（+0.21pp，旧版增益实为残差瓶颈）**、双曲分类头（−3.00pp）、傅里叶+双曲融合（−1.61pp）、MambaSSM（0.00pp）、KDA（梯度爆炸）
2. **统计功效是当前最大风险**：934 test 样本 95% CI ±3.2%，且 **FPS 用 `torch.randint` 随机起始点（`models/modules.py:66`），eval 本身非确定**——日志里每个 epoch 的 Test Accuracy 都是带噪声的单次采样。必须用固定 eval 种子 + 配对种子解决。
3. **机制层面的规律**：双曲当**度量/几何**用（注意力距离、选点网格）有正信号；双曲当**表示空间**用（exp/log map 嵌入、原型分类头、门控融合）全部失败或无效。这与 ECAF-GCN 的结论一致：**"特征要真在双曲里做变换"比"拿双曲距离当注意力分数"更关键，且双曲应放全局层级而非局部 K=24 组内。**
4. **本文档末尾新增「待测组件清单」**——把笔记里提出但**从未实现**的组件按优先级整理，供第二阶段直接取用。

## 二、线性注意力与 KDA 谱系（v3 时间编码依据）

v3 的 `KDACausalEncoder` 直接实现自 Kimi Linear 的 KDA 递推（gated delta rule + 逐通道遗忘门）。论文引用顺序建议：KimiLinear（机制定义）→ KimiK3（scale 验证）→ GatedDeltaNet（前身对比），其余两篇做谱系背景。

| 论文 | 一句话讲解 |
|---|---|
| Kimi Linear（arXiv 2510.26692, 2025） | KDA 定义出处：把 GDN 的标量衰减升级为逐通道对角门 Diag(α_t)，通道级遗忘 + delta rule 递推；v3 的 α/β 递推照此实现 |
| Kimi K3（arXiv 2607.24653, 2026） | KDA 大规模验证：2.8T MoE，3:1 KDA:MLA 混合 + NoPE + 1M 上下文；学长"kimi 不用 ROPE 用 KDA"的出处 |
| Gated DeltaNet（arXiv 2412.06464, ICLR 2025） | gated delta rule 前身：标量遗忘门 α_t + delta rule；KDA 的直接谱系来源 |
| DeltaNet（arXiv 2406.06484, 2024） | delta rule 的现代并行训练实现（chunk 并行）；为组内串行递推的并行化加速提供依据 |
| Linear Attention（arXiv 2006.16236, ICML 2020） | 线性注意力开山之作（线性化 softmax 成 RNN 递推形式）；整个谱系根基 |

## 三、每日阅读记录

### 早期精读（6 篇）

**1. SpikePoint（arXiv 2310.07189, ICLR 2024）**
- 定位：Point-based + SNN 脉冲网络，直接处理原始事件点，不转帧不建图，主打极低功耗。
- 方法：事件云 (x,y,t,p) → 点特征编码 → MLP 逐点变换 → SNN 脉冲层 → 全局聚合 → 分类。
- 局限：欧氏空间学习，难建模层级运动拓扑；SNN 表达能力有限。
- 启示：Point-based + 脉冲轻量路线，双曲空间可解决其层级建模不足。

**2. EventMamba（arXiv 2405.06116, TPAMI 2025）**
- 定位：Point-based + Mamba（SSM），线性复杂度建模长时序。
- 方法：希尔伯特曲线（HSFC）三维时空点 → 一维序列 → RWO 随机窗口偏移 → 多层 SSM。
- 局限：欧氏空间，只捕捉时序先后不建模树状层级。
- 启示：Mamba 长时序可参考，但双曲层级拓扑是差异化点。

**3. SECNet（arXiv 2412.20803, ICML 2026 Oral）—— 我们的基线**
- 定位：Point-based + 傅里叶频域特征，N-Caltech101 82.4%（point-based SOTA）。
- 方法：时空邻近性分组（极性 p 融入分组）→ FFT 到频域 → 频域特征聚合 → IFFT → 全局聚合 → 分类。
- 局限：欧氏空间，频域只捕捉全局统计、细粒度局部时序丢失。
- 启示：基线架构，**两次傅里叶变换是核心能力，替换会掉 ~10 点**。

**4. EHGCN（arXiv 2504.16616）—— 双曲事件路线参照**
- 定位：欧氏-双曲分层融合 + 运动感知超图 GCN，事件+双曲唯一参照。
- 方法：事件作图节点，时空邻近建边 → 庞加莱双曲空间 → 双曲图卷积 → 层级池化（手指→手→手臂→人体）→ 分类。
- 局限：必须显式建图，KNN 开销大、邻域超参敏感；双曲运算开销高。
- 启示：双曲层级建模有效性已验证，我们用 point-based 避免建图开销。

**5. ECAF-GCN（ICLR 2027 审稿版）—— 双曲事件检测【关键参考】**
- 定位：欧氏+双曲双分支 GCN，跨空间注意力融合，N-Caltech101 检测 mAP 0.706。
- 方法：共享时空编码器 → 欧氏 GCN 分支（B-spline 卷积抓局部）+ 双曲 GCN 分支（Möbius 变换抓全局层级）→ 双曲特征作 Query、欧氏特征作 Key/Value 的非对称跨空间注意力融合 → 检测头。
- **关键发现**：
  - 双曲+双曲仅 1.8M 参数达 0.683，**吊打欧氏+欧氏 55.8M 的 0.593**——双曲在事件数据上本身就强
  - 跨空间融合增益 **+0.062 > 双曲分支本身 +0.032**——**融合是增益大头**
  - 曲率 c 初始 0.4（与我们 HFECNet 一致）
- **对我们的启示（最重要）**：
  1. **双曲要放全局层级，不是局部 K=24 组内**——解释了为什么 `no_hyperbolic` 不掉点
  2. **特征要真在双曲里做变换（Möbius 线性+偏置）**，不是只拿双曲距离当注意力分数
  3. **欧氏+双曲并存比替换式强**，融合是增益大头

**6. PVAG（arXiv 2306.05239）—— v2 global_anchor 直接来源**
- 定位：点-体素吸收图，用 absorbing node 做全局信息聚合。
- 局限：absorbing node 是单一向量，表达能力有限。
- 启示：v2 的 global_anchor 借鉴此思想。**但 v2 实验显示 global_anchor 是拖累**（v2 41.20% vs v1 41.75%），v3 已移除 → **判无效**。

### 2026-10-10 批次（方法与架构）

**EventMG（NeurIPS 2025）—— 最接近的对手**
- 方法：事件时空建图 → 图特征逐级粗化 → 每级 Mamba 沿时间轴建模 → 各级融合 → 分类。
- 局限：仍需显式建图；欧氏空间无层级拓扑。
- **可落地用法**：远程聚合从单级选点升级为**多级粗化**——RemoteSelector 后加 2-3 级池化（K=24 局部 / K=64 中程 / 全局），每级 KDA 编码后拼接融合，再做双曲注意力。优先级：中。

**SpikingPointMamba（arXiv 2504.14371）**
- 定位：SNN + Mamba 结合点云，与我们 point-based 路线最重合的脉冲方法。
- **可落地用法**：输入编码层脉冲化——embed 后加 LIF 脉冲激活层。新增 `--spiking`。优先级：低（当前连续值网络改动大）。

**HyperbolicPointCloudCL（2025）—— 双曲点云对比学习**
- 方法：点云特征 → 庞加莱空间 → 双曲对比学习（正对拉近负对推远）→ 双曲 Transformer 聚合（Möbius）→ 曲率可学习。
- **可落地用法（高优先级，两条）**：
  1. 换 **Lorentz 模型**替代 Poincaré——解决边界 atanh 梯度尖峰。新增 `--hyperbolic_type lorentz`。（注：双曲注意力已部分采用 Lorentz 距离）
  2. 加**自监督对比损失**——同一物体不同窗口/增强样本在双曲空间拉近，双曲版 InfoNCE（权重 0.1）。缓解 3596 样本过拟合。
- 优先级：**高**。

**Multi-Delay Mixer（CVPR 2026）—— 多延迟时序混合**
- 方法：模拟生物神经元传导延迟，输入按多延迟档位（0/1/2/4 步）并行混合，各路径处理后融合；即插即用。
- **可落地用法**：KDA 输出后加多延迟混合层——按 0/1/2/4 步延迟分 4 条路径，各自 MLP 后融合。参数 <100K，与 KDA 互补。优先级：中。

**SDT（NeurIPS 2023）—— Spike-driven Transformer 基线**
- 启示：事件驱动稀疏计算思路与 RemoteSelector 的 top-G 稀疏选择理念一致。
- 可落地用法：主要 related work 引用 + 消融"全量远程点 vs top-G 选择"。优先级：低。

**TTPOINT（arXiv 2308.09993, ACM MM 2023）—— 张量化点云网络**
- 方法：点特征用 tensor train 分解表示与变换，替代 MLP 高维权重矩阵。
- **可落地用法**：局部组编码 MLP 用 TT 分解压缩（秩 r=4），Linear(64→64) 参数 4096→~1024。优先级：低（2.15M 已小于 3.5M 约束）。

**EVA（ICLR 2026）—— 异步事件特征学习**
- **可落地用法**：KDA 的 α 遗忘门输入从 x 改成 `concat([x, state_norm])`，让遗忘门感知历史状态。优先级：中。

**SSLA（arXiv 2603.06228, ECCV 2026）—— 稀疏线性注意力**
- **可落地用法**：远程聚合后备/对比方案——把双曲距离注意力换成稀疏线性注意力（kernel trick，O(G)）。新增 `--attn_type linear`。优先级：中（作为消融，证明双曲价值；G≈24 时 O(G²) 不是瓶颈）。

**HoloEvNet（arXiv 2602.04182）—— 全息嵌入 + 全局频谱门控**
- 方法：事件特征全息嵌入（复数域，保留相位）→ 全局频谱门控（可学习滤波器）→ 聚合 → 分类。
- **可落地用法**：升级 SECNet 固定 FFT——频域聚合后加可学习频谱门控（类似 SE-Net 的 squeeze-excitation），全局池化→MLP→sigmoid 门控后聚合。优先级：中（改基线组件，作基线增强对比）。

**LSFormer（arXiv 2605.13887）—— 低分辨率事件 Transformer**
- 分数 87.60%（T=10）是预印本自报，**需谨慎引用【待验证】**，暂不进对比表。
- 可落地用法：多尺度融合方式参考（门控残差融合）。优先级：低（与 EventMG 重叠）。

### 2026-10-11 批次（事件表征 / 线性注意力-SSM / 双曲优化）

**Event2Vec（ICML 2026）—— 事件到向量的直接表征**
- 方法：参数化空间嵌入（x,y → 可学习查找表）+ 卷积时间嵌入（t 经 1D 卷积）+ K-Means++ 聚合 → 标准 Transformer。
- **可落地用法**：输入 embed 升级为**分离式时空嵌入**——x,y 用空间查找表（240×180），t 用 1D 卷积，p 用可学习极性嵌入，三者拼接。新增 `--embedding_type separated`。优先级：中。

**PASS（NeurIPS 2025）—— 路径选择 SSM**
- 方法：PEAS 模块，SSM 选择性扫描，不同事件长度自适应选择扫描路径；跨推理频率泛化。
- **可落地用法**：KDA 的 α 改为**事件密度自适应**——α 输入加 `event_density = 组内事件数/时间跨度`，高密度组 α 更小（保留更久）。优先级：中。

**PointRWKV（2024）—— RWKV 迁移到点云**
- 方法：修改的多头矩阵值状态替代标量状态；动态注意力循环；并行局部分支；四级层级。
- **可落地用法**：KDA state 矩阵**低秩分解**——[B,S,D,D] 拆成 [B,S,D,r]×[B,S,r,D]（r=4），显存 167MB→~20MB/stage，让 V100-16GB 也能跑 KDA。新增 `--kda_low_rank r`。优先级：中。

**SpikingPointTransformer（AAAI 2025）—— 首个脉冲点云 Transformer**
- 方法：队列驱动采样直接编码（每时间步保留最有效支撑点）+ HD-IF 神经元 + 脉冲自注意力。
- **可落地用法**：FPS 分组改为**动态点数**——每组 K 按事件密度自适应，K∈[16,48] 均值 24。新增 `--dynamic_k`。优先级：低。

**HydraMamba（2025）—— 多头 SSM 全局点云学习**
- 方法：Shuffle Serialization + ConvBiS6（卷积+双向 S6）+ 多头 SSM + 层级聚合。
- **可落地用法**：KDA 改为**双向因果递推**（前向+后向，输出拼接 Linear 融合）。事件分类是离线任务，双向可利用完整时间上下文。新增 `--kda_bidirectional`。优先级：中。

**HyperbolicViT（2022）—— 双曲空间 ViT**
- 方法：patch 嵌入映射到庞加莱球 → 双曲自注意力（Q/K/V 在双曲空间用 Möbius 乘法和双曲距离）→ 双曲前馈（Möbius）→ 可学习曲率 → 双曲全局池化。
- **可落地用法（两条，都重要）**：
  1. **双曲 MLP**——远程聚合后的 MLP 改为 Möbius 矩阵乘法 + 双曲激活，特征全程在双曲空间直到分类前才投影回欧氏。新增 `--hyperbolic_mlp`。**当前双曲注意力后立刻 exp 映射回欧氏做 MLP，双曲几何的优势可能被欧氏 MLP 破坏。**
  2. **全双曲注意力**——Q/K/V 也 exp 到双曲空间，注意力在双曲空间计算，输出 log 回欧氏。
- 优先级：中（但按 ECAF-GCN 的结论，这两条可能是**关键**，见 §零第 3 条）。

**CurvatureAwareOpt（NeurIPS 2025）—— 曲率感知优化与 Riemannian AdamW【高优先级】**
- 定位：解决双曲学习中可学习曲率的不稳定性，**直接命中我们曲率无上界、NaN 风险的痛点**。
- 核心问题：可学习曲率 c 作为 Riemannian 流形参数时，优化器更新曲率后，双曲参数仍用旧曲率计算几何运算，产生几何不一致 → acosh 输入越界。
- 方法：
  1. **Curvature Aware Optimization**：先更新曲率 c，然后用 N-stabilize 映射把旧曲率流形上的参数映射到新曲率流形（切空间投影→log map→exp map→parallel transport）
  2. **Riemannian AdamW（RAdamW）**：AdamW 加权平均从欧氏改 Lorentz 质心，权重衰减在双曲空间有定义
  3. **Maximum Distance Rescaling**：D_max = acosh(x_tmax/√K)·√K，限制向量范数防 NaN，允许 fp16
- **可落地用法（高优先级）**：
  1. 短期：clamp + 小学习率(0.01x) + warmup 10 epoch（**当前方案，够用**）
  2. 中期：实现曲率更新后的切空间重映射，替换直接更新
  3. 长期：换 Riemannian AdamW，双曲参数用 RAdamW、欧氏参数用 AdamW
- 优先级：**高**（对应审查报告 L3；但注意：我们当前初始曲率已从 0.913 修为真 0.4，曲率的实际影响待测）

**PointTransformerV3（2024）—— 最新点云 Transformer**
- 可落地用法：FPS 分组替换为**体素哈希分区**（16×16×16 体素，每体素随机采样 K 点），替代 O(n²) FPS。新增 `--grouping voxel_hash`。优先级：低。

**EventDance（CVPR 2024）—— 事件-图像跨模态适应**
- 方法：跨模态对比学习 + 模态不变特征 + 伪标签自训练，无监督把图像知识迁移到事件。
- **可落地用法**：N-Caltech101 原始数据来自 Caltech101 图像（事件相机模拟生成），**天然有图像-事件配对**！用 ImageNet 预训练 ResNet 提图像特征，与事件特征做对比学习。优先级：低（需配对数据，实现复杂）。

**EventCLIP（2023）—— CLIP 迁移到事件零样本识别**
- 启示：缓解 3596 训练样本不足——自监督预训练 embed+局部编码层再微调。优先级：低。

### 2026-10-12 批次（双曲点云 / 事件时间编码 / 远程点采样）

**PointCHR（arXiv 2607.24052）—— 曲率感知双曲校正**
- 方法：分析点云在双曲空间中因曲率不均导致的**表示拥挤**（高曲率区域特征挤在一起）；根据局部特征密度**自适应调整曲率**，密集区域曲率增大（空间扩张）、稀疏区域减小。
- **可落地用法**：曲率从"固定 c=0.4"升级为**曲率感知校正**——每 stage 曲率按特征局部密度自适应，`c_s = c_init * (1 + γ·log(density_s))`。新增 `--curvature_mode adaptive`。优先级：中。

**Maximizing Asynchronicity（arXiv 2505.11165）—— 事件异步性最大化**
- 方法：不把时间戳归一化到 [0,1]，而是直接编码相邻事件的**时间间隔 Δt**；可变时间间隔位置编码；异步感知注意力。
- **可落地用法**：KDA 的 α 遗忘门加入 **Δt 感知**——`concat([x, state_norm, delta_t])`。间隔大→α大（快速遗忘），间隔小→α小（保留状态）。优先级：中。

**HyperIPC（arXiv 2409.15810）—— 双曲图像-点云对比学习**
- 可落地用法：跨模态双曲对比预训练（同 EventDance，但用双曲 InfoNCE）。优先级：低。

**Point-MASNet（IEEE JAS 2024）—— 掩码自编码器点云采样**

**5. HCNN — Fully Hyperbolic Convolutional Neural Networks（ICLR 2024）【高价值，直接可用】**
- 来源：`D:\论文\双曲方法论\2303.15919_HCNN_全双曲CNN.pdf`；代码 https://github.com/kSchwethlem/HyperbolicCV
- **核心论点（与我们完全一致）**：原话——"current HNNs in computer vision **rely on Euclidean backbones and only project features to the hyperbolic space in the task heads, limiting their ability to fully leverage the benefits of hyperbolic geometry**"。
  → 这是 ECAF-GCN 那条结论的严格版本，也**解释了我们双曲嵌入层失败（+0.21pp）的原因：只在出入口做投影，中间全是欧氏运算**。
- 基于 **Lorentz 模型**，把 CNN 基本组件全部双曲化：
  1. **双曲卷积层**
  2. **Lorentz Batch Normalization（LBN，式 6）**——关键工程技巧：用**加权 Lorentz 质心**（式 5，**有闭式解** `μ = Σνᵢxᵢ / (√(−K)·‖Σνᵢxᵢ‖_L)`）替代昂贵的 Fréchet 均值迭代；配合平行移动 + Fréchet 方差重缩放
  3. **Lorentz MLR 分类器（式 7）**——用**超平面** `H_{w,p} = {x ∈ Lⁿ_K | ⟨w,x⟩_L = 0}` 分类，而非"到原型的距离"；并用 Euclidean 重参数化消掉非凸约束 `⟨w,w⟩_L > 0`
- **对我们的两条可落地用法（重要）**：
  1. **`--hyperbolic_bn`**：做全双曲特征时把归一化换成 LBN（闭式质心，开销可控）。当前用欧氏 BatchNorm/GroupNorm，特征一进双曲就被破坏。
  2. **`--hyperbolic_mlr`：重试双曲分类头**。我们此前的双曲分类头用"距离→logits"（−3.00pp，logits 量级崩）。**Lorentz MLR 是另一套公式**（超平面 + 欧氏重参数化 + 可学习温度），**很可能救活这条路**——这是"已判无效但可能有救"的唯一组件。
- 优先级：**高**（P0-2/P0-3 的实现基础 + 复活双曲分类头）

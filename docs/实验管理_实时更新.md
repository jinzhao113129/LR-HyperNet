## 零、核心策略（2026-10-12 会议确定）

**最终目标**：发表一个**以双曲为核心的全新SOTA架构**，完全看不出来是SECNet的改进。

**当前阶段**：在SECNet强基线上逐个验证组件有效性，快速筛选有用组件，为最终全新架构提供素材。

**两阶段路线**：
1. **组件筛选阶段（当前）**：SECNet原始傅里叶聚合不动，每次只加一个组件，60epoch看相对排序
2. **架构整合阶段（下一步）**：基于有效组件 + 双曲核心，设计全新架构（聚合方式不能是傅里叶），再做消融

**最终架构候选方向**：
- 双曲嵌入为核心：输入→双曲映射→双曲局部+远程聚合→双曲原型分类
- 双曲频域聚合：傅里叶思想扩展到双曲空间
- 双曲Mamba/SSM：双曲状态空间模型替代傅里叶
- 16点选择+双曲聚合：RP1选点前端 + 双曲注意力后端
- **傅里叶+双曲并行融合**（新增）：保留傅里叶聚合，叠加双曲聚合分支，门控残差融合

**Baseline策略（学长指示 2026-10-12）**：
- 对比实验的baseline**直接引用各论文公开发表的最好成绩**，不需要自己复现SECNet
- 82.4%复现不再是阻塞项，我们自己跑的54%只是内部参考
- 论文对比表直接写"SECNet 82.4%（原文报告）"等公开成绩
- 精力放在新架构设计上，目标超过公开SOTA

## 四、82.4%复现结论（已破案）

- **82.4%是两阶段协议**：单窗训练 + 跨窗口聚合分类器（3×1080→1024→101）
- **单窗上限~60%**（论文Table 9自测），我们54.07%自洽
- **官方第二阶段模型未公开**，官方checkpoint架构与本地代码不匹配（attention 1080 vs 540，classifier 3240→1024→101 vs 1080→256→101）
- **全网无第三方复现**（GitHub 0 fork，6篇引用无复现报告）
- **官方仓库train_frequency.py的num_category choices=[10,40]跑不了101类**
- 论文中用"† our re-implementation"脚注 + 对齐协议下重训双方模型比较，是顶会可接受做法

## 五、双曲用法调研（本地论文库）

### 已读论文
| 论文 | 核心用法 |
|------|----------|
| Poincaré Embeddings(2017) | 双曲空间嵌入层级结构，指数级容量 |
| HGCN(2019) | 双曲图卷积，双曲空间做消息传递 |
| H2HGCN(2021) | 双曲GNN改进，恒定曲率+双曲线性层 |
| HyperbolicViT(2022) | Transformer token嵌入双曲空间，度量学习 |
| MERU(2023) | 双曲图文对比学习，双曲原型捕获层级 |
| HyperbolicPointCloudCL(2025) | 双曲点云对比学习，Möbius运算 |
| CurvatureAwareOpt(2024) | 可学习曲率的优化方法 |

### 双曲主要用法分类
1. **双曲嵌入层**：欧氏→双曲映射（exp map），利用层级结构
2. **双曲GNN/聚合**：双曲空间做图卷积/注意力
3. **双曲分类头/原型**：可学习双曲原型，logits=-双曲距离
4. **双曲对比学习**：双曲空间正负样本对距离拉推
5. **可学习曲率**：曲率作为可学习参数自适应几何

### 还没试过的、可能有效的双曲方向
1. **双曲嵌入层（最推荐）**：backbone输出→双曲映射→双曲空间组织→log map回欧氏→分类。避免双曲分类头logits量级问题
2. **双曲注意力权重**：保留傅里叶聚合，只把欧氏距离换成双曲距离计算注意力
3. **混合双曲-欧氏特征**：欧氏特征+双曲特征拼接后分类

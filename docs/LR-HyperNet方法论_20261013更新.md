## 一、问题与动机

事件相机输出异步事件流，每个事件含时间戳、坐标、极性。现有 point-based 方法（如 SECNet）存在三个核心不足：

1. 远程聚合在欧氏空间进行，无法表达事件数据的层级结构
2. 时间戳被当作普通特征维度，未显式建模时间因果序
3. 双曲曲率固定，限制不同 stage 的表达能力

## 二、架构范式：局部-远程分离聚合

基于 SECNet 的局部-远程分离范式，核心改动在远程聚合的几何空间和时间编码方式：

```
输入事件点云 → FPS 采样 + KNN 局部分组 → 局部特征提取 → 双曲远程聚合（核心改进）→ 分类头
```

事件相机输出一组 `(t,x,y,polarity)` 点。FPS 从一万个点选 2048 个代表点，每个代表点 KNN 拉周围 24 点成局部组；组内提取边缘/运动方向特征；远程聚合让各组交换信息（SECNet 用欧氏距离，改双曲距离）；汇总全局特征送分类头。聚合本质是注意力加权求和。

## 三、核心方法（形式化）

### 3.1 双曲远程聚合（v1）
- 欧氏基线：SECNet 原版
- 双曲映射：特征映射到庞加莱球
- 庞加莱双曲距离 + 双曲注意力权重（基于双曲距离而非内积）+ Möbius 加法加权聚合，最后 log 映射回欧氏
- 可学习曲率：每 stage 独立参数（保证正定）

### 3.2 时间因果序编码（v2/v3.1）
多频正弦位置编码 + KDA（v3，已弃用，见 §四）

### 3.3 全局锚点（v2，PVAG 启发）—— 已验证无效
选邻居时除了"跟我像不像"还看"跟全局平均像不像"，避免只选相似组导致冗余。**实验显示 global_anchor 是拖累**（v2 41.20% vs v1 41.75%），v3 已移除。

### 3.4 曲率优化三件套（v3.1）
问题：可学习曲率训练中易异常增大，Poincaré 球半径缩、特征挤向原点、注意力退化为均匀分布。
1. 单独学习率：curvature 学习率为基础 1/100
2. L2 正则化：约束曲率偏离初始值
3. Warmup 固定：前 10 epoch 固定曲率，之后放开

### 3.5 Lorentz 双曲模型（v3.1，替代 Poincaré）
Poincaré 的 atanh/exp 在边界梯度趋于无穷导致不稳定；Lorentz 模型用双曲面 + Lorentz 内积/距离，无边界奇异性。

### 3.6 双曲原型分类头（路线 A）—— 已验证无效（-3.00pp）
同预算消融显示双曲在聚合层无增益（v3.1 双曲 36.83% vs 欧氏 37.47%）。文献中双曲增益最常出现在分类层（N-Caltech101 类别有 WordNet 层级）。实现为 Lorentz 双曲原型，logits = −双曲距离。**结果 -3.00pp（44.54%），logits 量级问题，已放弃。**

## 四、KDA 路径失败分析（v3，已弃用）

- KDA 用 gated delta rule 因果递推，组内按时间戳排序 24 步串行递推，状态矩阵 [D×D]
- **两次实验均在 epoch 8 Test 冻结于 5.03%（常数预测）**，无 NaN
- 根因：24 步串行递推的反向梯度链爆炸；残差连接+前向状态范数裁剪只约束前向，无法抑制反向梯度异常
- 递归结构在小数据（3596 样本）上训练不稳定，纯前馈（sin/cos 位置编码）更可靠

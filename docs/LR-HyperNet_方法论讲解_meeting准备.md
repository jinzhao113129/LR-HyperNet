## 一、问题与动机

### 1.1 事件相机分类的特点

事件相机输出异步事件流 $\mathcal{E} = \{(t_i, x_i, y_i, p_i)\}_{i=1}^N$，每个事件包含时间戳 $t$、坐标 $(x,y)$、极性 $p \in \{+1,-1\}$。

**核心挑战**：
- 事件是**点云形式**（非规则网格），无法直接用 CNN
- 事件具有**时间因果序**（异步触发，先后顺序有意义）
- 事件数据具有**层级结构**（边缘→物体→场景）

### 1.2 现有方法的不足

| 方法 | 代表 | 不足 |
|---|---|---|
| 帧-based | SNN、CNN+体素 | 量化丢失时间精度，计算冗余 |
| Point-based | SECNet、TTPOINT、SpikePoint | 纯局部 KNN/FPS，无远程语义聚合；时间当普通坐标用 |
| Graph-based | EHGCN | 图构建开销大，端到端训练困难 |

### 1.3 我们的核心观察

1. **远程语义相关事件的发现与聚合是真空位**：现有 point-based 方法的层次结构全是纯局部 KNN/FPS，没有显式建模远程依赖
2. **时间信息利用不足**：point-based 方法把时间戳当普通特征维度，embed 层是线性的，只能学到仿射函数
3. **双曲几何可能适合层级结构**：但需要实证验证（目前证据偏弱）

## 二、方法论总览

### 2.1 架构范式：局部-远程分离聚合

我们基于 SECNet 的局部-远程分离范式，核心改动在**远程聚合的几何空间**和**时间编码方式**：

```
输入事件点云 (t,x,y,p)
    ↓
FPS 采样 + KNN 分组（局部）
    ↓
局部特征提取（PointNet++ 风格）
    ↓
┌─────────────────────────────────────┐
│  远程聚合（我们的核心改进）          │
│  - 远程点选择：特征距离 top-K        │
│  - 聚合几何：欧氏 / 双曲（消融）     │
│  - 时间编码：多频 sin/cos            │
│  - 曲率优化：单独lr + L2 + warmup   │
└─────────────────────────────────────┘
    ↓
分类头（101 类）
```

### 2.2 版本演进

| 版本 | 核心改动 | 状态 | 结果 |
|---|---|---|---|
| v1 | 双曲远程聚合（Poincaré），可学习曲率 | ✅ 完成 | b8/30ep = 38.33% |
| v2 | + sin/cos 时间编码 + 全局锚点 | ❌ 作废 | time_enc 通道错位 bug（编码了极性不是时间） |
| v3 | + KDA gated delta rule 时间编码 | ❌ 弃用 | epoch8 冻结于 5.03%，梯度爆炸 |
| v3.1 | 修复 time_enc + Lorentz + 曲率优化三件套 | 🔄 在跑 | epoch12 = 29.76%（还在爬） |
| 欧氏对照 | 与 v3.1 同配置，唯一变量 hyperbolic_type=euclidean | 🔄 在跑 | epoch2 = 21.09%（生死线） |

## 三、核心方法（形式化表述）

### 3.1 局部-远程分组（Local-Remote Grouping）

**这是架构里最可能的主创新点，与双曲无关。**

对每个 stage，先做局部 KNN 分组，然后用特征距离选择远程语义相关点：

$$\mathcal{N}_R(i) = \text{topK}_j \left( \|\mathbf{h}_i - \mathbf{h}_j\|_2 \right)$$

远程点经过注意力加权聚合后与局部特征拼接。

**定位**：可以描述为"学习式稀疏图"——局部 KNN 是空间邻接边，远程 topK 是语义边。不用写一行 GNN 代码就占住 graph 叙事位。

### 3.2 双曲远程聚合（v1 基础，待消融判定）

**欧氏远程聚合**（基线）：
$$\mathbf{h}_i^{\text{remote}} = \sum_{j \in \mathcal{N}_R(i)} a_{ij} \cdot \mathbf{h}_j, \quad a_{ij} = \text{softmax}_j\left(-\|\mathbf{h}_i - \mathbf{h}_j\|^2 / T\right)$$

**双曲远程聚合**（我们的 v1/v3.1）：

将特征映射到 Lorentz 双曲面 $\mathbb{H}^d_c = \{ \mathbf{x} \in \mathbb{R}^{d+1} : -\langle \mathbf{x}, \mathbf{x} \rangle_L = 1/c, x_0 > 0 \}$：

$$\exp_c^{\mathbf{0}}(\mathbf{v}) = \left(\cosh(\sqrt{c}\|\mathbf{v}\|), \frac{\sinh(\sqrt{c}\|\mathbf{v}\|)}{\sqrt{c}\|\mathbf{v}\|} \mathbf{v}\right)$$

Lorentz 距离（无边界奇异性）：
$$d_c(\mathbf{x}, \mathbf{y}) = \frac{1}{\sqrt{c}} \operatorname{arcosh}(-c \langle \mathbf{x}, \mathbf{y} \rangle_L)$$

双曲注意力权重：
$$a_{ij}^c = \text{softmax}_j\left(-d_c(\mathbf{h}_i^{\mathbb{H}}, \mathbf{h}_j^{\mathbb{H}})\right)$$

**可学习曲率**：$c = |c_{\text{param}}| + 10^{-4}$，每个 stage 独立。

### 3.3 时间编码（v2/v3.1，已修复）

对时间戳做多频正弦位置编码：
$$\text{PE}(t)_{2f} = \sin(2\pi \cdot 2^f \cdot t), \quad \text{PE}(t)_{2f+1} = \cos(2\pi \cdot 2^f \cdot t), \quad f \in \{0,1,2,3\}$$

与空间特征拼接：$\mathbf{e}_{\text{in}} = [x, y, p, \text{PE}(t)_0, \ldots, \text{PE}(t)_7] \in \mathbb{R}^{12}$

**关键修复**：v2 原代码错误取了 `xyz[..., 3:4]`（极性 $p$），sin/cos 编码 $p \in \{-1,+1\}$ 退化为常数。v3.1 修复为 `xyz[..., 0:1]`（时间戳 $t$），实测 sin/cos 通道 std≈0.70，携带时间信息。

### 3.4 曲率优化三件套（v3.1，稳定性改进）

1. **单独学习率**：curvature 参数 lr = 基础 lr × 0.01
2. **L2 正则化**：$\mathcal{L}_c = 0.01 \sum_s (c_s - c_{\text{init}})^2$
3. **Warmup 固定**：前 10 epoch 固定曲率，让特征空间先稳定

### 3.5 Lorentz 替代 Poincaré（v3.1）

Poincaré 的 $\operatorname{atanh}$ 在边界处梯度尖峰，Lorentz 模型全空间梯度有界。修复了 lorentz_exp_origin 的结构性 bug（sinh 项缺 1/√c 因子，导致输出不满足流形约束）。

## 四、KDA 路径的失败分析（v3，已弃用）

KDA（gated delta rule）做因果递推，24 步串行：
$$\mathbf{S}_t = \text{Diag}(\boldsymbol{\alpha}_t) \mathbf{S}_{t-1} - \beta_t \mathbf{k}_t (\mathbf{k}_t^T \mathbf{S}_{t-1}) + \beta_t \mathbf{k}_t \mathbf{v}_t^T$$

两次实验均在 epoch 8 冻结于 5.03%（常数预测）。根因：24 步串行递推反向梯度链太长，梯度爆炸。教训：递归结构在小数据集（3596 样本）上不稳定，纯前馈结构更可靠。

## 五、重大认知更新：82.4% 是两阶段协议

### 5.1 之前的困惑

SECNet 官方报告 N-Caltech101 = 82.4%，我们最好复现 = 54.07%，差 28 点。

### 5.2 真相（经 arXiv 原文 + GitHub commit 历史 + 官方 checkpoint 结构三重验证）

**官方 README 原话**：
> "For CIFAR10-DVS and N-Caltech101, we first train SECNet on single sliding window, then train a simple classifier to get the results cross a sample."

**82.4% = 两阶段协议**：
1. 第一阶段：在单个 30ms 滑窗上训练 SECNet（单窗能力上限论文自测约 **60%**，Table 9）
2. 第二阶段：训练跨窗口聚合分类器（3×1080→1024→101，3240=3×1080），得到视频级结果

**我们单窗跑 54% 完全自洽，不是 bug。**

### 5.3 公开代码不完整实锤

- `train_frequency.py` 的 `--num_category choices=[10,40]` 跑不了 101 类
- 第二阶段聚合模型的定义与训练脚本**从未公开**
- 官方 checkpoint 是未公开的第二阶段模型，在公开 FECNet 上永远加载不上
- 全网 0 fork、6 篇引用无独立复现、HuggingFace 0 模型

### 5.4 对我们的影响

- 基线比较应在**同单窗协议**下进行，不需要复现 82.4%
- 新架构和基线都用单窗数据（百度官方 train 3596/test 934），对比公平
- 复现争议可以写成论文附录的 due diligence（给作者发邮件 + 开 issue + 仓库缺陷证据链）

**关键结论（同 b8/30ep 直接对比）**：
- 基线 44.00% > 欧氏对照 37.47% > v1 38.33% ≈ v3.1 36.83%
- **双曲 vs 欧氏：差 0.64pp，双曲在当前用法（聚合层）无增益** ← 关键裁定
- **问题出在 local-remote grouping 架构本身（欠拟合），不在双曲**
- 5类 sanity 证明容量无 bug（96.51% 过拟合），欠拟合是优化问题

### 6.4 优化器修复（GN + GradAccum4）

欠拟合根因分析（双 Claude 一致）：
1. **BN 在 b8 下统计噪声大**（长尾类每 epoch 只见几个样本）→ GroupNorm 修复
2. **有效 batch 太小** → 梯度累积 ×4 修复
3. 去掉 balanced_sampler + logit_adj（双重长尾修正叠加过度，Train 从 1%→3% 学不动；logit_adj 符号 bug 已修复但去掉这两个 flag）

**当前效果**：Train 从 18% 升到 ~31%（epoch16 对比无修复版同期 ~15%），方向正确，继续观察能否爬到 90%+。

### 6.5 路线A：双曲原型分类头（已实施）

**假设**：双曲增益在文献中最常出现在**分类层**而非聚合层。N-Caltech101 类别有 WordNet 层级结构，双曲原型能利用层级先验。

**实现**：欧氏 backbone（远程聚合用欧氏）→ 分类头换成 Lorentz 双曲原型分类器：
- 欧氏特征 [B,1080] → Linear → 切空间 [B,64] → exp → Lorentz 点 [B,65]
- 可学习类原型 [101,64] → exp → [101,65]
- logits = -双曲距离(x, prototype)  [B,101]

**验证**：CPU 5 项测试全过（前向/反向/Lorentz函数/端到端/参数量）。参数量 1,887,304（比标准头少 227,556，因为标准头 1080→256→101 较大）。

**对比逻辑**：168741 vs 168574 唯一变量是分类头（双曲原型 vs MLP），若 168741 明显更高 → 双曲在分类层有增益，路线A成立。

### 6.6 关键认知：当前"新架构比基线差"不成立

- 基线 54.07% = b32/150ep，Train 99.86%（充分拟合）
- v1 38.33% = b8/30ep，Train 才 39%（严重欠拟合）
- 同预算 b8/30ep：基线 44.00% vs v1 38.33%，确实差 6pp——但这是架构欠拟合，不是双曲问题
- **GN+GA 修复版正在验证欠拟合能否解决**，若 Train 能到 90%+，差距可能大幅缩小

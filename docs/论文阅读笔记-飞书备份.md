# 一、核心思想

使用**父概念靠近原点、子概念靠近流形边界**这套设定，利用双曲空间指数扩张的几何特性，可以天然表达包含/从属的层级关系，不会像欧氏空间那样把层级关系挤变形。让模型更好地利用部件/整体、语义包含关系，在局部观测、少样本、细粒度任务上获得更好的泛化性能。

# 二、适用场景

什么时候可以用双曲空间，关键在于**数据结构是否天然存在树状/层级/包含父子关系**，而且层级很深、子类很多。

# 三、使用方法

1. **特征提取**：普通网络照常提取特征，输出欧氏向量，这一步和普通模型完全一样。
2. **指数映射**：通过指数映射，从欧氏切空间映射进双曲流形。
3. **双曲空间计算与层级约束**：

   - 距离不用欧氏距离/余弦相似度，改用**双曲测地线距离**（双曲空间两点之间最短路径）
   - 设计损失，强制满足层级：父概念靠近原点，子概念靠近边界

     - **层级正则**：控制嵌入的模长，父向量模更小，子向量模更大
     - **三元组/对比损失**：同类父子拉近，不同类推开
     - **POP偏序损失**：约束子概念落在父概念的双曲锥内
4. **对数映射（可选）**：转回欧氏切空间做最终预测。如果分类头、分割头不好直接在流形上算，就用log映射把双曲向量变回欧氏向量，再做预测。
5. **训练优化**：优化器不能直接用普通Adam，要用**双曲空间的黎曼优化器**（黎曼梯度下降），沿着流形曲面更新参数。

# 四、两种双曲平面模型

这6篇论文主要体现了两种双曲平面：**庞加莱圆盘**和**洛伦兹模型**。二者都是2维双曲空间的不同数学模型，不是两种不同的双曲面，是同一个双曲空间，两种不同的坐标表示方式。

| 模型 | 主要用途 | 特点 |
|-|-|-|
| 庞加莱圆盘 | 点云任务 | 可视化更方便 |
| 洛伦兹模型 | Transformer、图网络、注意力 | 数值更稳定 |

# 五、双曲流形与为什么用双曲嵌入

**双曲流形**：一个空间，随便挑一个很小的局部，都是一模一样的双曲几何（均匀向内凹）。

**为什么使用双曲嵌入**：主要原因在于树的节点是指数变多，欧氏空间的容量只是线性增长，装不下；双曲空间容量指数增长，刚好匹配树。

| 空间 | 容量增长 | 结果 |
|-|-|-|
| 欧氏空间 | 离中心越远，可用空间/周长只按半径线性增加 | 大量深层节点只能堆在一块，向量互相重叠，区分不开，距离信息失效 |
| 双曲空间 | 离中心越远，空间体积/周长指数增长 | 节点可以均匀散开，不会挤在一起，层级远近关系能很好用距离表达 |

# 六、MinkowskiNet（特殊一篇）

**MinkowskiNet**（4D Spatio-Temporal ConvNets: Minkowski Convolutional Neural Networks）和其他几篇不太一样。区别主要在于：双曲系列论文聚焦**特征嵌入流形改造**，显式引入层级先验；而MinkowskiNet聚焦**底层点云数据表示与卷积算子创新**，工作在普通欧氏平坦空间，不引入任何负曲率双曲几何。

## 1. 广义稀疏卷积和COO稀疏张量

- 用稀疏张量存储点云体素数据，格式为COO（坐标列表）格式，保存两大核心成员：**坐标矩阵**和**特征矩阵**
- 空白无点的体素完全不存储、不参与计算，解决大场景点云稠密体素卷积显存爆炸、无效计算多的痛点
- 通过**子流形稀疏卷积**，只在"原本就有点"的位置更新特征，不会把特征扩散到空白空间

## 2. 闵可夫斯基时空

狭义相对论里的时空，3维空间+1维时间；曲率=0，属于欧氏类平坦空间。它是4D时空但不是真实四维几何空间。

> 💡 MinkowskiNet**不使用相对论的闵可夫斯基度量**，只是借用这个"空间+时间"的概念，网络内部并不采用相对论的伪欧度量。

卷积怎么做这个4D输入？论文提出**hybrid kernel（混合核）**，意识到直接做完整4D立方体卷积不合理：

- **空间部分(x,y,z)**：用普通3D立方卷积核，捕捉物体几何
- **时间维度t**：只用十字形核，只匹配同一个(x,y,z)位置在不同时刻t的点

## 3. 输入形式

| 方法 | 输入形式 | 适用场景 |
|-|-|-|
| MinkowskiNet | 原始点云做体素离散化转为整数voxel坐标 | 房间、街道这类大场景 |
| 双曲点云论文 | 固定数量浮点原始点，不做体素化 | 单个物体（飞机、椅子） |

# 七、事件相机与闵可夫斯基时空的联系

事件相机输出的每一个事件可表示为**时空点(x,y,t)**。结合MinkowskiNet可以将事件流组织为以(x,y,t)为坐标的扩展COO稀疏张量，利用广义稀疏卷积处理异步稀疏事件。

如果是事件相机（2D像素空间+时间）：

- **空间维度(x,y)**：2D卷积核抓邻域像素
- **时间维度t**：十字型核，匹配同一个像素(x,y)不同时刻发生的事件

不需要做完整(x,y,t)三维立方体卷积，降低参数量。

# 九、SpikePoint

**定位**：Point-based + SNN 脉冲网络，直接处理事件相机原始事件点，不转帧、不构建显式时空图，面向事件动作识别，主打极低功耗。

## 提出原因

### 1. 传统 ANN（人工神经网络）

大多把事件累积成帧 / 体素网格。

- 问题：事件本身是稀疏异步的，转帧会引入大量冗余、丢失时序信息；推理功耗高，不适合边缘硬件。

### 2. 旧 SNN 脉冲神经网络处理事件

同样习惯把事件转成体素网格输入 SNN。

- 问题：体素是规整网格，强行把稀疏事件塞入网格，破坏事件原生点结构；空间分辨率越高，网格越大，算力越高。

## 关键概念

### 事件帧

- 本质：二维图片
- 做法：选定一段时间窗口（比如 50ms），窗口内所有事件，只看空间坐标 (x,y)，忽略事件发生的先后时间。

### 事件体素网格

- 本质：把时间切成多段，做成三维立方体
- 空间维度：H、W；新增时间维度 T
- 做法：把同样的总时间窗口，切分成 N 个时间小段（time bin），每个时间小段单独生成一张 2D 事件图，沿时间维度堆叠
- 输出形状：时间片 × 高 × 宽

### SNN

- SNN 是脉冲神经网络，神经元累积电位，到阈值就发射 0/1 脉冲；异步、低功耗，但是训练需要替代梯度
- SpikePoint 把它用在事件点云，不用转帧/体素

## 方法流程

本文直接输入 Event Cloud 事件云，输入就是一堆原始事件点 (x,y,t,p)，再通过点特征编码模块把原始四维信息 (x,y,t,p) 映射成高维特征向量。再使用简单的 MLP 映射，直接对每个点特征做变换，特征全程保持点的结构，不转网格，再通过 SNN 脉冲层，最后所有点的脉冲特征全局聚合，得到整个事件序列的全局向量，最后输出动作类别。

## 优点

- SpikePoint 提出 Point-based 脉冲网络，直接处理原始事件云，无需网格化预处理
- 模型极轻量，参数量和功耗很低，适合边缘设备
- 保留事件相机原生的稀疏异步点结构，避免网格化带来的坐标/时间量化损失

## 缺点

- 模型在欧氏空间学习特征，难以建模事件流内在的层级运动拓扑，远距离、有层级关联的事件点难以建立有效的依赖，这时可以使用双曲空间来解决这个问题
- SNN 表达能力有限，仅支持动作分类任务，不支持目标检测

# 十、EventMamba

**问题**：长时序建模能力弱。

事件流往往很长，物体持续运动，相隔很远时间产生的事件，存在运动关联。

- Transformer 可以建模长距离依赖，但复杂度 O(n²)，事件点数量一多，计算量爆炸，速度很慢
- Mamba（SSM 状态空间模型）：线性复杂度 O(n)，擅长长序列，但是原版 Mamba 是给规整图像序列设计的
- 事件云是无序点集合，不能直接丢进 Mamba；如果随便排序，会破坏时空邻近性，性能大幅下降

## 关键概念

### Mamba

- 一种选择性状态空间模型，一种无 Attention 的序列建模骨干网络
- 亮点：Mamba 的 SSM 参数由输入 token 动态决定，模型可以选择性记住、遗忘序列里的信息
- 线性复杂度 O(n)，擅长长序列

### RWO 随机窗口偏移

训练时，每次窗口起点随机偏移，增强鲁棒性。

## 方法流程

本文把依靠希尔伯特曲线的特性：在空间上靠近的点，映射到一维序列之后，依然相邻。事件点是三维时空 (x,y,t)，HSFC 遍历整个时空空间，把离散点串成一维序列，送入 Mamba。再通过 RWO 随机窗口偏移把一维序列切分成窗口送入 Mamba。固定窗口会破坏平移不变性，这样训练时每次窗口起始位置随机偏移，可以增强模型平移不变性，用于提升泛化能力。再通过多层 SSM 模块，逐层提取由粗到细的时空特征，线性复杂度更加高效，最后多任务输出。

## 优点

1. Point-based 范式，不建图、不网格化，直接处理原始事件云，保留事件稀疏异步特性
2. 引入 Mamba，线性复杂度高效建模长时序运动依赖，长事件序列性能显著优于 SpikePoint
3. 多任务能力，支持分类+回归（相机位姿估计），适用场景更广
4. HSFC+RWO 的组合，解决无序点送入序列模型的难题，保留时空局部性和平移不变性

## 局限性（项目切入点，非常关键）

1. 全部在欧氏空间做特征学习。只能捕捉时序依赖，没有建模事件内在的层级运动拓扑
2. 时序建模只沿着一维序列，没有显式建模层级拓扑。Mamba 捕捉的是时序先后，不是树状层级
3. 对超大尺度事件流（极高分辨率、超长时间），扩展性依然有限。事件点数量爆炸，计算开销会持续上涨
4. 依旧不面向目标检测任务，以全局特征为主，缺少细粒度定位

# 十一、SECNet

**问题**：事件相机在高速、长时间采集场景下，事件点数量会爆炸，处理超大事件流开销很高。

## 关键设计

### Event Group & Sampling 事件分组采样

- 一般分组就按时空位置分组；分组完成之后，再把 p 当成一个数字，和 x,y,t 拼接在一起送入 MLP
- 而该分组就考虑极性，两个事件哪怕时空位置很近，如果亮度变化方向相反（一个变亮、一个变暗），也不一定分到同一组

### 傅里叶频域特征提取

- 不在时域做大量逐点邻域运算，而是把特征变换到傅里叶频域，在频域完成特征聚合与提取
- 频域天然适合全局统计特征，减少大量逐点交互计算

## 方法流程

本文首先按照时空邻近性对海量事件点进行分组，同时把极性 p 融入分组规则。分组后的点特征，通过 FFT 变换到频域，在频域做特征聚合、信息交互；之后 IFFT 逆变换回到时空域。最后聚合所有点特征，输出类别，用于事件分类任务。

## 优点

1. Point-based 范式，不建图、不网格化，直接处理原始事件云，保留事件稀疏异步特性
2. 傅里叶频域设计，超大事件流下可扩展性强。事件点数量巨大时，算力增长平缓，解决 SpikePoint、EventMamba 随点数增加算力爆炸的问题
3. 事件分组采样把极性融入分组逻辑，过滤静态冗余事件，减少无效计算
4. 全局特征提取能力强，适合长时间、高分辨率大规模事件序列

## 局限性（项目切入点）

1. 特征学习依旧在欧氏空间。频域只是特征处理手段，没有建模事件的层级运动拓扑
2. 频域捕捉的是全局统计信息，细粒度局部时序细节会丢失。频域擅长全局运动，对精细局部运动建模偏弱
3. 任务局限：仅支持分类任务，缺少目标检测所需要的细粒度定位能力
4. 频域变换有固有量化损失，精细的时序信息在 FFT/IFFT 过程会有少量丢失

# 十二、EHGCN

**问题**：欧氏空间痛点在于树状层级结构，节点数量指数增长，欧氏空间会发生拥挤，嵌入向量挤在一起，区分不开。

## 方法流程

本文把每个事件 (x,y,t,p) 作为图的节点，时空邻近的事件节点之间建立边，再将事件初始特征，从欧氏空间映射到双曲空间（庞加莱圆盘模型），在双曲空间内，邻居节点之间传递信息（图卷积消息传递），逐层合并节点：代表局部部件的事件节点，聚合生成代表更大整体的节点。一层一层向上合并，构建层级：手指 → 手 → 手臂 → 人体，这个过程就是显式学习部件-整体的层级拓扑。最后最终得到物体整体的层级特征，输出类别，完成事件动作/物体分类。

## 优点

1. 采用双曲几何，天然适合建模事件流的部件-整体层级运动拓扑，解决欧氏空间节点拥挤问题
2. 双曲图卷积+层级池化，可以显式挖掘事件之间树状层级关联，在有部件层级的物体分类任务效果最好
3. 相比欧氏 GNN，层级结构的嵌入区分度更高

## 局限性

1. Graph-based 范式，必须显式构建时空图。要搜索 KNN 邻居、建立边；事件点数量大时，边数量爆炸，计算与内存开销巨大，可扩展性差
2. 图构建依赖邻域搜索，邻域选取超参敏感，容易引入噪声边，影响层级学习
3. 任务局限：只做分类，不支持目标检测
4. 双曲运算本身计算开销高于欧氏空间算子

# 十三、综述

## Introduction

**事件相机数据特点**：事件相机不输出固定帧图片，输出异步稀疏事件 (x,y,t,p)，只有像素亮度发生变化才产生事件，具备微秒级时间分辨率、高动态范围。

## 两大分支

### 1. Dense-based（稠密表示）

把离散事件转为事件帧/体素网格，复用 CNN。

- 优点：成熟、易实现
- 缺点：时空量化损失，丢失精细时间戳，破坏原生稀疏异步特性

### 2. Sparse-based（稀疏表示）

不网格化，保留原始事件 (x,y,t,p)，保留细粒度时序信息。稀疏分支再划分为：Graph-based（图表示）、Point-based（点表示）

#### Graph-based Representation

将事件流构建时空图，事件作为图节点，时空邻近节点之间建立边，使用 GNN 消息传递建模事件依赖。图方法擅长层级拓扑建模，但代价高，难以处理大规模事件流。

#### Point-based Representation

事件直接看作无序时空点云集合 (x,y,t,p)，不建图、不 KNN 邻居搜索、不存在节点之间显式边，直接对点集合做特征学习。

1. 无需 KNN、不用显式建图，省去巨大建图开销，海量事件点下扩展性显著优于 Graph-based
2. 完整保留原始事件精确 (x,y,t,p)，无网格化、无建图带来的信息损失
3. 架构简洁，契合事件相机原生稀疏异步特性，推理速度更快

**局限性**：现有 Point-based 方法全部在欧氏空间学习特征。仅能学习局部时空特征、长时序依赖，无法显式建模部件-整体树状层级运动拓扑；层级结构嵌入欧氏空间会发生节点拥挤，远距离层级关联难以区分。

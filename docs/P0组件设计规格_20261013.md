## P0-1 `--curvature_opt`：曲率感知优化三件套

**来源**：CurvatureAwareOpt（NeurIPS 2025）

**动机**：可学习曲率在训练中易异常增大 → Poincaré 球半径缩小、特征挤向原点、注意力退化为均匀分布。现有代码只用 `abs+1e-4` 保正，无任何优化约束。

**实现**（改 `train_frequency_ncaltech.py`）：
1. **单独学习率**：把所有曲率参数（`named_parameters()` 中名字含 `curvature` 或 `c_raw` 的参数）归入独立 param group，`lr = args.learning_rate * 0.01`。
2. **L2 正则**：`L_c = 0.01 * mean((softplus(raw_c) - c_init)**2)`，其中 `c_init = 0.4`，加入总 loss。
3. **Warmup 固定**：前 10 个 epoch 曲率 param group 的 `lr = 0`（或对该 group 做 `requires_grad` 切换），第 11 个 epoch 起恢复为 `base_lr*0.01`。

**验收**：CPU 前向 5 组 PASS；训练 3 epoch 不报错；TensorBoard/日志能打印曲率值。

**注意**：需先确认模型确实暴露了可学习曲率参数（`--hyperbolic_attention` / `--hyperbolic_embedding` 路径下才有）。

## P0-2 `--hyperbolic_mlp`：双曲 MLP（Möbius 线性 + 偏置）

**来源**：HyperbolicViT（2022）/ HGCN（2019）的 MöbiusLinear

**动机**：当前 `HyperbolicAttention` 后**立刻 log 映射回欧氏**再做 MLP，双曲几何的优势可能被后续欧氏 MLP 破坏。ECAF-GCN 的结论是"**特征要真在双曲里做变换**（Möbius 线性+偏置），不是只拿双曲距离当注意力分数"。

**实现**（改 `models/FECNet.py`）：
- 在 `HyperbolicAttention` 输出后、log 回欧氏**之前**，插入双曲变换：
  1. `exp_map` 进入双曲空间
  2. **Möbius 矩阵乘**：`W ⊗_c x`（`W` 为可学习矩阵，零初始化或小初始化）
  3. **Möbius 偏置加**：`x ⊕_c b`（`b` 零初始化）
  4. **双曲激活**：用 `exp_map(ReLU(log_map(x)))` 或保范数的双曲 ReLU
  5. `log_map` 回欧氏
- 参数量控制：`W` 用 stage 通道数，不要引入大矩阵。
- 与现有 `--hyperbolic_attention` **串联**（该 flag 打开时才有双曲特征可变换）。

**验收**：CPU 前向 PASS；`--hyperbolic_attention --hyperbolic_mlp` 组合可跑；参数量增量 < 100K。

## P0-3 `--hyperbolic_attention_full`：全双曲注意力

**来源**：HyperbolicViT（2022）

**动机**：现有 `--hyperbolic_attention` 只把**注意力分数的距离**换成 Lorentz 双曲距离，而 **Q/K/V 仍在欧氏空间**。这一步升级为 Q/K/V 也进双曲空间。

**实现**（改 `models/FECNet.py`）：
- 新增 `HyperbolicAttentionFull` 类（或扩展现有类）：
  1. Q/K/V 线性投影后 `exp_map` 到双曲空间（Lorentz 或 Poincaré，与现有实现保持一致）
  2. 注意力分数用双曲距离（现有已实现，复用）
  3. 输出 `log_map` 回欧氏
- 保留 0.1 残差注入的现有形式：`x = x + 0.1 * x_hyper`。
- **与 `--hyperbolic_attention` 互斥**（都替换注意力路径）→ 加 guard，同开抛 `ValueError`。

**验收**：CPU 前向 PASS；与 `--hyperbolic_attention` 同开抛错；参数量增量可控。

## P0-4 `--spectral_gate`：可学习频谱门控

**来源**：HoloEvNet（arXiv 2602.04182）

**动机**：SECNet 的 FFT 是**固定的**，频域特征未经选择。加可学习门控可自适应增强重要频率、抑制噪声频率。

**实现**（改 `models/FECNet.py`）：
- 在 SECNet 频域聚合**之后**加 squeeze-excitation 式门控：
  1. 全局池化（对 group 维）→ 得到逐通道描述子
  2. 两层 MLP（降维比 16：`C→C/16→C`）+ sigmoid
  3. 逐通道相乘回频域特征
- 位置：每个 stage 的傅里叶聚合输出处。

**验收**：CPU 前向 PASS；参数量增量 < 50K；default-off 数值与基线一致。

## P0-5 `--hyperbolic_bn`：Lorentz 批归一化（LBN）

**来源**：HCNN（ICLR 2024，arXiv 2303.15919）式 5-6
**原文**：`D:\论文\双曲方法论\2303.15919_HCNN_全双曲CNN.pdf`；代码 https://github.com/kSchwethlem/HyperbolicCV

**动机**：一旦特征进入双曲空间，用欧氏 BatchNorm/GroupNorm 会**破坏几何**。这是做"全双曲"路线的必需配套件。HCNN 的核心论点是：只在出入口投影、中间全欧氏，就**无法真正获得双曲几何的收益**——这正好解释我们双曲嵌入层为何只有 +0.21pp。

**实现**（改 `models/FECNet.py`）：
1. **加权 Lorentz 质心（闭式解，式 5）**：
   `μ = Σᵢ νᵢxᵢ / (√(−K) · ‖Σᵢ νᵢxᵢ‖_L)`
   —— 用它替代迭代的 Fréchet 均值，保证开销可控（这是 HCNN 的关键工程技巧）
2. **平行移动** `PT^K_{μ_B→β}(x)`：把特征从 batch 均值移到可学习参数 `β`（不改方差）
3. **Fréchet 方差重缩放（式 6）**：先平行移动到原点 → 切空间内按 `γ·(·/√(σ²_B+ε))` 缩放 → 再平行移动回 `β`
4. 输出 `LBN(x) = exp^K_β( PT^K_{0→β}( γ · PT^K_{μ_B→0}(log^K_{μ_B}(x)) / √(σ²_B+ε) ) )`
5. 曲率 `K` 复用现有可学习曲率参数

**验收**：CPU 前向 PASS；数值有限（注意 acosh/atanh 边界，沿用现有三层兜底：clamp 1−1e-6 + loss 有限性检查 + grad clip 5.0）；`--hyperbolic_bn` 单独开与 default-off 对比参数量。

**依赖**：只有特征真在双曲空间的路径（`--hyperbolic_attention` / `--hyperbolic_mlp`）才有意义；单独开启时若无可归一化的双曲张量，应打印警告并按 no-op 处理。

## P0-6 `--hyperbolic_mlr`：Lorentz MLR 分类头【复活已判无效组件】

**来源**：HCNN（ICLR 2024）式 7 + Ganea 2018 / Shimizu 2020 的 Poincaré MLR
**原笔记状态**：我们的双曲分类头用"**距离→logits**"（101 个可学习原型，logits = −双曲距离），**结果 −3.00pp，原因是 logits 量级问题，已判无效**。

**为什么值得重试**：HCNN 的 Lorentz MLR 是**完全不同的公式**：
- 用**超平面**而非原型：`H_{w,p} = {x ∈ Lⁿ_K | ⟨w,x⟩_L = 0}`
- 用 **Euclidean 重参数化**消掉非凸约束 `⟨w,w⟩_L > 0`：
  `w ∈ T_p Lⁿ_K` 参数化为 `w̄ ∈ T_0 Lⁿ_K = [0, a·z/‖z‖]`（`a ∈ ℝ, z ∈ ℝⁿ`），`w̄` 再平行移动到 `p`
- 即：**把"距离比较"换成"超平面符号距离"，且参数化保证良态**

**实现**（改 `models/FECNet.py`）：
1. 新增 `LorentzMLRHead` 类：可学习 `p`（切空间参数化）+ `a, z`（每个类别一组，或共享 `p`）
2. logits 用负的 Lorentz 超平面距离（含可学习温度 `τ` 缩放，解决原版的量级问题）
3. 曲率可学习，初始 0.4
4. 与现有 `--hyperbolic_classifier` **互斥**（都替换分类头）→ 加 guard

**验收**：CPU 前向 PASS，输出 `(B,101)` 且 logits 量级合理（std 不应比欧氏 head 差一个数量级）；与 `--hyperbolic_classifier` 同开抛错。

**优先级说明**：这是**唯一一个"已判无效但可能有救"**的组件——之前失败是公式选错（原型距离 vs 超平面），不是"双曲分类头不行"。

## 优先级与建议顺序（2026-10-13 更新）

| 顺序 | 组件 | 理由 |
|---|---|---|
| 1 | **P0-1 曲率三件套** | 成本最低、直击已知风险；**曲率是唯一没试过的旋钮**（修复 C 把初始曲率 0.913→0.4 后，双曲注意力 49.893%→49.572%，说明曲率对结果敏感） |
| 2 | **P0-2 双曲 MLP** | 直接检验"真在双曲里做变换"这一核心假设（HCNN 的核心论点） |
| 3 | **P0-6 Lorentz MLR** | 复活唯一"可能有救"的已判无效组件；公式有据（ICLR 2024） |
| 4 | **P0-3 全双曲注意力** | 双曲注意力的自然升级（已有 +2.04pp 确认基础） |
| 5 | **P0-5 Lorentz BN** | P0-2/P0-3 的必要配套件（否则双曲特征被欧氏归一化破坏） |
| 6 | **P0-4 频谱门控** | 属基线增强（非双曲），增益较确定但 novelty 较低 |

> **组合关系**：P0-5（LBN）是 P0-2/P0-3 的配套设施，建议在 P0-2 验证有效后再上；P0-6 独立于其他组件。

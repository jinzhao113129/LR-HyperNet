# SECNet 两次傅里叶变换实现拆解

> 学长会议要点：SECNet 的精髓 = 两次傅里叶变换（空间域 + 时间域）+ 加权 agg。
> 本文档逐行拆解 FECNet.py 中的实现，为后续改进提供基础。

## 1. 整体结构

FECNet 的每个 stage 包含：
1. **LocalGrouper**：FPS 采样 + KNN 局部分组，提取局部特征
2. **空间域傅里叶（fft_sptaial）**：在局部邻居维度做 rFFT
3. **Attention 聚合**：对傅里叶变换后的特征做注意力加权
4. **时间域傅里叶（fft_temporal）**：在 group/空间位置维度做 rFFT
5. **门控融合（gated fusion）**：local branch × sigmoid(global branch)

```
输入点云 → LocalGrouper → [B, N, D, S] (N=组数, D=特征维, S=邻居数)
    → fft_sptaial (dim=1, 特征维) → GELU → Attention
    → [B, N, D'] → fft_temporal (dim=1, group维) → GELU
    → x_local (conv) × sigmoid(x_global (avgpool+conv)) → 输出
```

## 2. fftlayer 类（核心组件）

```python
class fftlayer(nn.Module):
    def __init__(self, weight):
        super().__init__()
        # weight: [F, ..., 2]，最后一维是实部/虚部
        self.weight = nn.Parameter(weight)

    def forward(self, x):
        # x: [..., C]，在最后一维做 rFFT
        x_freq = torch.fft.rfft(x, dim=-1)  # 实信号快速傅里叶变换
        # 可学习复数权重：实部 + i*虚部
        w = torch.complex(self.weight[..., 0], self.weight[..., 1])
        x_freq = x_freq * w  # 频域加权（逐频率乘可学习系数）
        x_out = torch.fft.irfft(x_freq, dim=-1, n=x.shape[-1])  # 逆变换回时域
        return x_out
```

**关键点**：
- `rfft` 只计算正频率部分（实信号的傅里叶变换有共轭对称性），节省一半计算
- 可学习权重是**复数**（实部+虚部），初始化时实部=1、虚部=0（即初始化为恒等变换）
- 频域加权 = 对每个频率分量学习一个缩放+相位偏移
- `irfft` 逆变换保证输出维度与输入一致

## 3. 第一次傅里叶：空间域（fft_sptaial）

**位置**：FECNet.py forward，LocalGrouper 输出之后

```python
# x 来自 LocalGrouper: [B, N, D, S]
# B=batch, N=组数(2048/1024/512), D=特征维(64/132/268), S=邻居数(24)
x = x.permute(0, 1, 3, 2)  # → [B, N, S, D]
b, n, d, s = x.size()
x = x.reshape(-1, d, s)  # → [B*N, D, S]，把 batch 和 group 合并

x = self.fft_sptaial_list[i](x)  # rFFT 在 dim=-1 = S（邻居/空间维度）
x = F.gelu(x)
x = x.permute(0, 2, 1)  # → [B*N, S, D']
```

**权重形状**：
```python
fft_sptaial_weight = nn.Parameter(torch.cat(
    (torch.ones(D//2 + 1, S, 1),   # 实部初始化为1
     torch.zeros(D//2 + 1, S, 1)),  # 虚部初始化为0
    dim=-1))
# [F, S, 2]，F = D//2+1（rFFT 的频率数）
```

**作用**：在每个 group 的 24 个局部邻居之间做傅里叶变换，学习邻居间的**空间频率模式**。
- 低频分量 = 邻居间的整体趋势/平均特征
- 高频分量 = 邻居间的细节差异/边缘
- 可学习复数权重 = 选择性放大/抑制不同空间频率

## 4. Attention 聚合

```python
att = self.aggregation_list[i](x)  # Attention(D')，输出 [B*N, S] 的注意力权重
x = torch.bmm(att.unsqueeze(1), x).squeeze(1)  # 加权求和 → [B*N, D']
x = x.reshape(b, n, -1)  # → [B, N, D']
```

**作用**：对 24 个邻居的傅里叶变换后特征做注意力加权聚合，得到每个 group 的一个特征向量。

## 6. 门控融合（gated fusion）

```python
# local branch
x_local = self.conv_list[i](x)  # Linear2Layer，[B, D', N] → [B, 1, N]?
x_local = self.bn_local_list[i](x_local)

# global branch: mean pool → conv → expand → gate
x_global = F.adaptive_avg_pool1d(x, 1)  # [B, D', 1] 全局平均池化
x_global = self.group_conv_list[i](x_global)  # Linear2Layer
x_global = self.bn_global_list[i](x_global)
x_global = x_global.expand(-1, -1, n)  # → [B, D', N] 广播到所有位置

# gated fusion: 局部特征 × sigmoid(全局特征)
x = x_local * torch.sigmoid(x_global)
x = x.permute(0, 2, 1)  # → [B, N, D']
```

**作用**：
- `x_local` = 每个位置的局部特征（经过两次傅里叶变换后）
- `x_global` = 全局上下文（平均池化后再卷积）
- `sigmoid(x_global)` = 门控信号，决定每个位置/通道的重要性
- 乘法 = 用全局上下文调制局部特征（类似 SE-Net 的通道注意力，但作用在空间+通道）

## 7. 两次傅里叶的区别总结

| 维度 | 第一次（fft_sptaial） | 第二次（fft_temporal） |
|---|---|---|
| 作用维度 | 局部邻居 S（24） | group 空间位置 N（2048/1024/512） |
| 输入形状 | [B*N, D, S] | [B, D', N] |
| 频率数 | D//2+1 | N//2+1 |
| 语义 | 邻居间的空间频率 | 全局位置间的空间频率 |
| 类比 | 局部纹理/边缘检测 | 全局结构/形状感知 |

## 8. 对我们新架构的启示

### 8.1 双曲 + 傅里叶的结合点
- 当前 LR-HyperNet 保留了 FECNet 的两次傅里叶，只替换了 LocalGrouper
- **可以探索**：在双曲空间做傅里叶变换（双曲傅里叶分析已有理论基础，但实现复杂）
- **更实际**：在远程聚合后加一个傅里叶层，学习远程邻居间的频率模式

### 8.2 远程聚合的傅里叶化
- 当前远程聚合用注意力加权，可以替换为"远程邻居维度的傅里叶变换 + 可学习频域权重"
- 这相当于把 SECNet 的空间傅里叶思想从局部 24 邻居扩展到远程 16 邻居
- 参数量增加很小（每个 stage 一个 [G//2+1, D, 2] 的复数权重）

### 8.3 时间编码与傅里叶的关系
- v2 的多频正弦时间编码本质上也是一种傅里叶特征（固定频率的 sin/cos）
- SECNet 的可学习傅里叶权重 = 数据驱动的频率选择
- **可以探索**：让时间编码的频率也可学习（从固定 2^0-2^3 改为可学习频率）

### 8.4 门控融合的改进
- 当前门控用全局平均池化，可以改为**双曲全局锚点**（v2 已有 global_anchor）
- 门控信号可以用双曲距离计算，而不是欧氏平均池化

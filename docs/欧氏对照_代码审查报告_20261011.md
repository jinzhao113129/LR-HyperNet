## 审查项逐项

### 1. EuclideanRemoteAggregator 与双曲版同构 ✓

| 组件 | 双曲版 | 欧氏版 |
|---|---|---|
| anchor | 欧氏质心 → exp 到双曲空间 | 欧氏质心（直接用） |
| 注意力距离 | 双曲距离 / 曲率 | softmax(-||x-anchor||² / T) |
| 变换 | Möbius 线性（切空间） | 普通 Linear（命名 mobius_linear 保持对照） |
| 可学习超参 | 曲率 c（1 标量） | 温度 T（1 标量，abs+1e-4 保正） |
| 输出 | out_proj + 残差 + LayerNorm | out_proj + 残差 + LayerNorm（完全一致） |

参数量：双曲版 2,115,372 = 欧氏版 2,115,372，**差 0**。

### 2. LocalRemoteGrouper 分支 ✓

`assert hyperbolic_type in ["poincare", "lorentz", "euclidean"]` 已更新，三分支正确选择聚合器。

### 3. optimizer 温度分组（超出"只加选项"的唯一改动）✓ 合理

AdamW 参数分组把 `'hyper_agg.temperature' in n` 并入曲率参数组（lr×0.01、weight_decay=0）。

**理由**：否则欧氏版温度落入 base_params，被 wd=1e-4 拉向 0 → `softmax(-d²/T)` 饱和成 one-hot → 欧氏基线被不公平削弱。此匹配只命中 euclidean 模型（双曲版 temperature 是普通属性不在 named_parameters 里），对已有训练路径零影响。

### 4. sanity_5class 过滤逻辑 ✓

- 在 data/label/mark reshape 对齐后按同一 mask 过滤
- 强制 `num_category=5`、`epoch=min(epoch,50)`

- 实际筛出：train 839 / test 214（类别 0-4 各 213/168/93/333/32）

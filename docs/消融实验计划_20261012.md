# LR-HyperNet 消融实验计划（统一配置版）

> 目标：在完全一致的配置下，逐组件验证有效性，产出可直接用于论文的消融表
> 日期：2026-10-12

## 一、标准配置（所有消融实验必须严格遵守）

| 项目 | 值 | 说明 |
|------|-----|------|
| 数据集 | 百度盘单窗 N-Caltech101 | train 3596 / test 934，(t,x,y,p)，10240点 |
| batch_size | 8 | V100-16GB限制 |
| epoch | 60 | 看收敛趋势即可（学长：慢热型不存在） |
| 优化器 | AdamW lr=0.001 wd=1e-4 | 与SECNet一致 |
| 调度器 | CosineAnnealingLR(60) | |
| 数据增强 | 无 | aug会降低性能（170240验证：32.66% < 38.22%） |
| dropout | **0** | 与B0（纯SECNet）一致，保证控制变量干净；168574无dropout拿到38.22% |
| 时间编码 | time_enc（多频正弦）或KDA | 作为待验证组件；另加A0'原始时间戳作底线 |
| 双曲类型 | **poincare** | 与170805(P0)一致，2×2矩阵必须同类型 |
| 随机种子 | 固定42 | A0和A3各跑3个种子建立噪声带；其余单种子 |
| 报告口径 | **best test acc（统一）** | 所有实验统一用峰值，内部迭代可用；论文表建议val选点报test |

## 四、需要补做的实验（3个）

1. **A0**：欧氏+time_enc+top-k，无aug+drop0.1，b8/60ep
   - 脚本：复用168574配置，加--dropout 0.1，确认无aug
   - 目的：标准配置下的纯基线

2. **A1**：欧氏+KDA+top-k，无aug+drop0.1，b8/60ep
   - 脚本：A0基础上加--kda
   - 目的：KDA单独贡献

3. **A2**：双曲+time_enc+top-k，无aug+drop0.1，b8/60ep
   - 脚本：A0基础上加--hyperbolic_type poincare（或lorentz）
   - 目的：双曲单独贡献

## 五、执行顺序

1. **立即**：杀掉170351（配置不标准，浪费卡）
2. **等170805完整曲线**：确认60ep收敛、A3最终量级 → 决定是否放行A0-A2
3. **提交A0（3种子）、A1、A2、A0'**：4个实验，V100，每个约6h
4. **A0/A1/A2出结果后**：做2×2可加性检查，确认组件无负交互
5. **A3补跑2个种子**（已有1个=170805），凑齐3种子
6. 选点消融（A4/A5/A6）排队中，等结果
7. **最终验证**：A3在b32/150ep补跑一次（A100/H100），验证增益可迁移
8. 所有结果出来后，统一整理消融表

## 六、风险与注意事项

1. **统计功效（最关键）**：test集934样本，35%准确率下单次二项噪声±3点（95%CI）。小于3点的差异不可分辨。KDA预期增量2-3点，单种子可能测不出来 → A0和A3必须跑3种子
2. **A3≤A0风险**：如果full model（KDA+双曲）打不过欧氏基线，说明组件有负交互，消融叙事不成立 → 需做2×2可加性检查（A3−A2 ≈ A1−A0？）
3. **170351配置不标准**（aug+drop0.3），建议杀掉止损，结果不进消融表
4. **170805收敛确认**：必须看完整曲线是否平台化，用曲线证明60ep够用，不能凭学长断言
5. **batch=8的lr问题**：b8下梯度噪声大、有效步长相对b32变大，组件增益可能不迁移到高收敛域 → 最终A3需在b32/150ep补跑一次验证
6. **A0和B0差距判据**：A0明显低于B0才是结构有问题；且因dropout已统一为0，判据可用
7. **V100显存**：A0/A1/A2都是b8，168574已验证可跑
8. **报告口径统一**：所有实验用best test acc；论文表建议val选点报test

## 三、核心发现

### 1. 推理可复现性问题（已解决）

- `models/modules.py` 的 FPS 用 `torch.randint(0,N)` 随机选起始点
- 同一 checkpoint 的 eval 波动达 **2.6pp**（46.15%~48.72%），和组件效应同量级
- **训练日志里的 Test Accuracy 全部带噪声，不可信**
- 修复：`tools/extract_preds.py --eval_seed 42`，同种子跨节点可复现（934/934逐样本一致）
- **所有结论必须基于固定seed推理，不能看训练日志**

### 2. A1归因：旧版双曲选点+4.71pp的真正原因

- `fps_parameter` 训练后变为 [1.45, 1.55, 1.30, 1.17]（t,x,y,p），x维度缩放最多
- 缩放坐标让FPS中心重叠率仅14.5%，空间覆盖率+2.6%
- **增益来自"尺度感知的FPS采样"，不是双曲几何本身**
- 尺度归一化FPS（172843）是关键验证实验

### 3. 创新点方向

- **核心创新点候选1：尺度归一化FPS**（等172843结果）
- **核心创新点候选2：16个点远程选择**（学长强调，等RP1修复版结果）
- **正反馈零件：双曲注意力**（已确认显著）
- **辅助组件：双曲选点**（有正向趋势但不显著）

```python
import numpy as np
from scipy import stats
import sys

def mcnemar(npz1, npz2, name1="A", name2="B"):
    d1, d2 = np.load(npz1), np.load(npz2)
    p1 = d1["y_pred"] if "y_pred" in d1 else d1["preds"]
    p2 = d2["y_pred"] if "y_pred" in d2 else d2["preds"]
    y = d1["y_true"] if "y_true" in d1 else d1["labels"]
    acc1, acc2 = (p1==y).mean()*100, (p2==y).mean()*100
    win = ((p2==y)&(p1!=y)).sum()
    lose = ((p1==y)&(p2!=y)).sum()
    print(f"{name1}: {acc1:.4f}%  {name2}: {acc2:.4f}%  Δ: {acc2-acc1:+.4f}pp")
    print(f"Win/Lose: {win}/{lose}")
    if win+lose > 0:
        p = stats.binomtest(min(win,lose), win+lose, 0.5).pvalue
        print(f"McNemar p: {p:.4f}  {'***SIG***' if p<0.05 else 'not sig'}")

if __name__ == "__main__":
    mcnemar(sys.argv[1], sys.argv[2], sys.argv[3] if len(sys.argv)>3 else "A", sys.argv[4] if len(sys.argv)>4 else "B")
```

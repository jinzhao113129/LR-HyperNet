## 七、2026-10-11 会议新增要点

### 方法层面
| # | 要点 | 说明 |
|---|------|------|
| 1 | **16个点的选择可探索** | 远程聚合的邻居点怎么找，欧氏空间和双曲空间里特征可能不一样 |
| 2 | **双曲对时间敏感** | 学长认为双曲对时间感知更敏感，对树状结构数据效果更好 |
| 3 | **SECNet 精髓 = 两次傅里叶变换** | 一次空间域 + 一次时间域，两次加权和 aggregation；基于 SECNet 改要么看不出 SECNet 影子，要么学精髓再创新 |
| 4 | **SpikePoint 可参考** | 参数量小/轻量高效，ICML oral/spotlight，很有含金量 |
| 5 | **EventMamba 可参考** | 事件范式 + Mamba 结合的思路 |

### 实验策略（重要！）
| # | 要点 | 说明 |
|---|------|------|
| 1 | **可以 all in 再消融** | 所有组件一起加，有效果后再一个一个减；主表证明 SOTA，消融表证明每个点都涨点 |
| 2 | **小批量先试，有效果再上全量** | 不要一上来就跑全量 |
| 3 | **看收敛曲线，收敛了就没效果了** | 别指望后面奇迹涨点 |
| 4 | **慢热型不存在** | 好方法很快就能看出压过一头，跑 50-100 轮看趋势就够 |
| 5 | **超参数影响甚小** | 除非极端值，否则不用太纠结 lr/batch 等 |
| 6 | **组件冲突正常** | 两个有效组件加起来没效果也正常，试不同组装方式；消融实验可以动 trick（不报告所有排列组合） |
| 7 | **KDA 梯度爆炸** | 加平滑 / layer norm；也可能 KDA 是大模型技术不适合这个领域 |

# 白跑实验的有用结论（2026-10-13）

> 虽然这些实验因为bug/噪声/方向不对不能作为最终组件有效性依据，但它们产出了有价值的反面证据和方法论发现。

## 一、架构层面的硬结论

### 1. SECNet两次傅里叶聚合绝对不能替换
- **证据**：替换为自定义欧氏聚合后，epoch8只有23.98%，纯SECNet同时期33.83%，差约10个点
- **结论**：空间域rfft + 时间域rfft + gated fusion是SECNet的核心能力，自定义聚合（无论欧氏还是双曲）都远不如它
- **影响**：最终架构如果要"看不出SECNet影子"，不能简单替换聚合，需要重新设计等价或更强的频域聚合机制

### 2. 双曲嵌入层放在欧氏backbone后无效
- **证据**：修复版双曲嵌入层仅+0.21pp，旧版+1.07pp实际是LayerNorm残差结构效果
- **结论**：验证了HCNN（ICLR 2024）的核心论点——"current HNNs rely on Euclidean backbones and only project features to hyperbolic space in task heads, limiting their ability to fully leverage hyperbolic geometry"
- **影响**：双曲不能只放在分类头/嵌入层，需要在backbone内部就用双曲运算（双曲注意力、双曲MLP才是正确方向）

### 3. 双曲分类头用"到原型距离"是错的
- **证据**：双曲分类头-3.00pp（44.54% vs 47.54%）
- **结论**：Poincaré球上"到原型的距离"作为logits不合适，可能因为距离分布过于集中/缺乏温度缩放
- **启发**：HCNN的Lorentz MLR分类头用超平面而非距离，可能救活这个组件
- **影响**：双曲分类头方向不放弃，换公式重试

### 4. 傅里叶+双曲门控残差融合无效
- **证据**：-1.61pp（45.93%）
- **结论**：简单的门控残差（gating = sigmoid(linear(concat(euclidean, hyperbolic)))）不能有效融合两个分支
- **启发**：不代表双曲不能和傅里叶合作，可能需要更精巧的融合方式（如频域内的双曲操作、注意力融合）

## 二、方法论发现

### 5. FPS随机采样导致eval不可复现（最重要的发现）
- **证据**：同一checkpoint，不同eval运行的Test Acc波动2.6pp（46.15%~48.72%），和所有组件效应同量级
- **根因**：models/modules.py:66的FPS用torch.randint(0,N)随机选起始点，训练脚本只设一次种子
- **结论**：点云模型的eval必须固定采样种子，否则组件排名完全不可信
- **影响**：第一阶段所有旧版结果都被噪声污染，需要用固定eval_seed重新验证；论文级结论必须报多种子均值±std

### 6. 并发实验的产物文件名必须包含所有变化维度
- **证据**：3个推理作业用不同eval_seed写同一个last.npz，后写覆盖先写，导致McNemar p从0.0097变成0.0609（假阴性）
- **结论**：固定文件名+并发=静默覆盖=假结论
- **影响**：以后所有批量实验的输出文件名必须包含seed、组件名等所有变化维度

### 7. 数据增强在这个数据集上降低性能
- **证据**：5种增强下32.66%，无增强38.22%
- **结论**：N-Caltech101单窗数据本身已经足够多样化，增强（随机旋转/平移等）反而引入噪声
- **影响**：标准消融配置不用aug

### 8. 网络容量无bug，全量低性能是欠拟合/优化问题
- **证据**：5类子集50epoch，Train 96.51% / Test 89.72%
- **结论**：模型能记住5类，说明容量足够；101类下性能低是因为数据量/训练轮数/优化问题，不是网络结构bug
- **影响**：不需要加大模型，需要优化训练策略（学习率、轮数、数据利用）

## 三、组件方向的反面证据

### 9. MambaSSM在这个配置下无效
- **证据**：旧版0.00pp（47.54%），修复版在跑（21/60，目前41.4%还早）
- **结论**：状态空间模型替代傅里叶聚合的方向在小配置下不work
- **影响**：Mamba方向暂时放弃，专注双曲主线

### 10. KDA（知识蒸馏注意力）不适合小模型
- **证据**：旧版ep24梯度爆炸取消
- **结论**：KDA是大模型技术（需要教师模型的注意力分布作为目标），在1.9M参数的小模型上梯度不稳定
- **影响**：修复版在跑（加了self_in防御断言），如果仍不稳定就放弃

### 11. 有效组件叠加可能冲突
- **证据**：注意力+嵌入层组合+0.43pp，不如单独注意力+2.04pp
- **结论**：不是所有有效组件都能1+1>2，嵌入层的欧氏MLP可能破坏双曲注意力的几何结构
- **影响**：叠加实验需要谨慎，P0双曲MLP就是为了解决这个问题（在双曲空间内做MLP而不是回欧氏）

## 四、复现与基线的结论

### 12. SECNet官方82.4%是两阶段协议
- **证据**：README明确写了"single window training + cross-window aggregation classifier 3×1080→1024→101"，单窗上限论文自测~60%
- **结论**：我们单窗54.07%（b32/150ep）与论文自洽，82.4%需要第二阶段模型（未公开）
- **影响**：baseline直接引用各论文公开成绩，不需要自己复现82.4%

### 13. 旧版"高结果"可能是bug+噪声的叠加
- **证据**：双曲选点旧版50.86%（+3.32pp），修复版35轮才45.5%；双曲嵌入层旧版48.61%（+1.07pp），修复版47.75%（+0.21pp）
- **结论**：代码bug（错误坐标、恒等映射）+ FPS噪声可能共同制造了假增益
- **影响**：任何组件在宣称有效前，必须经过：代码审查→bug修复→固定eval_seed→McNemar显著性检验，四步缺一不可

## 五、从"bug版本"中提炼的潜在创新点

### 14. 错误坐标选点为什么有效？值得研究
- **现象**：双曲选点旧版用缩放后xy坐标选点，结果50.86%（比基线高3.32pp），修复版用原始坐标反而低
- **假设**：缩放后的坐标空间可能改变了点之间的相对距离分布，导致选出来的16个点更均匀/更有代表性
- **可探索方向**：尺度感知选点（scale-aware selection）——在多个尺度下选点，而不是只用原始坐标
- **前提**：需要先用固定eval_seed验证旧版是否真的稳定有效，排除噪声

### 15. LayerNorm残差结构本身有增益
- **现象**：双曲嵌入层旧版的LayerNorm残差瓶颈结构带来了约+0.86pp（旧版48.61% vs 修复版47.75%）
- **结论**：在SECNet的stage之间加LayerNorm残差连接可能是一个简单有效的改进
- **可探索方向**：给SECNet的每个stage输出加LayerNorm+残差连接，作为独立组件验证

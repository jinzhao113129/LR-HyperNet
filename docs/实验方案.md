# 实验方案：SECNet 基线 + HFECNet 双曲模型（N-Caltech101）

> 版本：v1.0
> 日期：2026-10-06
> 作者：豆包
> 状态：待用户确认后执行（等租卡）

## 1. 实验目标

1. **复现 SECNet 基线**：在 N-Caltech101 上跑通 SECNet（FECNet），验证官方配置下的准确率（预期 ~82%）
2. **验证双曲空间有效性**：HFECNet（双曲聚合增强）在相同配置下对比 SECNet，验证双曲聚合能否提升 Point-based 事件分类性能
3. **消融分析**：通过 4 个消融版本，定位双曲模型的增益来源（双曲聚合 / 可学习曲率 / 质心锚点）

## 2. 数据集

| 配置项 | 值 |
|---|---|

## 3. 实验矩阵

### 3.1 主实验（4 个 run）

| Run | 模型 | 说明 | 关键配置 |
|---|---|---|---|
| R1 | SECNet (FECNet) | 基线复现 | num_point=8192, group=512, neighbors=24 |
| R2 | HFECNet | 双曲聚合增强 | 同 R1 + 双曲聚合 + 可学习曲率 |
| R3 | HFECNet-no_hyperbolic | 消融：去掉双曲聚合 | 同 R2，聚合换欧氏注意力 |
| R4 | HFECNet-fixed_curvature | 消融：曲率固定 1.0 | 同 R2，曲率不可学习 |

### 3.2 扩展实验（视结果决定）

| Run | 模型 | 说明 |
|---|---|---|
| R5 | HFECNet-no_centroid | 消融：锚点用第一个点（非质心） |
| R6 | SECNet + 预训练 | 从 SECNet 预训练权重初始化双曲模型（迁移学习） |
| R7 | 双曲 + rp1 远程邻域 | 结合 rp1 远程邻域建图 + 双曲 GCN（二期） |

## 5. 评价指标

### 5.1 主指标

- **Overall Accuracy（整体准确率）**：所有样本正确分类比例

### 5.2 辅助指标

- **Per-class Accuracy**：每类准确率（分析哪些类提升/下降）
- **Per-class Std**：类间准确率标准差（稳定性）
- **混淆矩阵**：错误模式分析
- **参数量 / FLOPs / 显存 / 推理延迟**：模型代价对比

### 5.3 记录方式

- 每 epoch：train loss, train acc, test acc
- 保存：best model（按 test acc）、训练曲线图、最终 confusion matrix

## 6. 实验流程

```
1. 租卡（V100 16GB 或 32GB，先 1 张）
2. 检查数据完整性（train.h5/test.h5）

4. R2 HFECNet 训练（150 epochs）

6. 分析结果：准确率对比、消融差异、per-class 分析
7. 可视化：训练曲线、混淆矩阵、per-class 对比
8. 写实验报告
```

## 8. 预期结果与分析

### 8.1 成功标准

- [ ] SECNet 基线 ≥ 78%（低于官方 82.4% 需排查：数据划分差异 / 超参数差异）
- [ ] HFECNet 相对 SECNet 有提升（≥ +0.5% 视为有效）
- [ ] 消融：去掉双曲聚合掉点（验证双曲有效）；固定曲率小幅掉点；no_centroid 影响较小

### 8.2 可能结果与应对

| 结果 | 应对 |
|---|---|
| 双曲提升明显（>+2%） | 继续做 R6 预训练微调 + R7 远程邻域 |
| 双曲小提升（+0.5~2%） | 调双曲超参（曲率初值、K、聚合层数），做 R5 锚点消融 |
| 双曲无提升/掉点 | 分析原因：可能是数据量不足 / 双曲聚合设计问题 / 8192点+101类不适合；尝试 2048 点配置 |
| 基线就低于 78% | 先解决基线问题（数据检查、超参调优），再谈双曲 |

### 8.3 深入分析维度

1. **类别增益分析**：双曲模型在哪些类提升？是否是有层级结构的类（如 vehicle、animal 类）？
2. **错误模式对比**：双曲模型是否解决了基线的特定错误？
3. **特征可视化**：PCA/t-SNE 对比双曲 vs 欧氏特征分布
4. **层级结构验证**：双曲空间中，同类样本是否聚成层级结构？（可视化双曲嵌入）

## 9. 风险与注意事项

1. **数据划分不一致**：我们的 train/test 是按 mark 8:2 划分的，SECNet 官方可能有不同划分 → 对比官方数字时需注明口径
2. **8192 点加载慢**：h5 加载 14297×8192×4 = 468MB，每 epoch 全量读取 → 考虑缓存或优化
3. **双曲运算慢**：双曲聚合涉及 exp/log map，比欧氏慢 → 记录训练速度，若太慢考虑降低 K
4. **Claude 写的代码需审查**：hyperbolic_fecnet_ablation.py 和 train 修改需我（豆包）审查后才能用于正式实验
5. **租卡成本**：先租 1 张 V100 16GB（4点/小时），跑 R1 看基线，再决定是否长期跑

## 4. 协作流程

### 4.1 豆包 → Claude（交编码任务）

**必须提供：**
```
【背景】一句话说清楚当前在做什么
【任务】具体要写什么代码/脚本
【接口定义】输入输出、参数、返回值
【文件路径】写到哪个文件
【依赖】依赖哪些已有文件/模块
【不要做】明确禁止的事（如不要改某文件、不要删东西）
【验收标准】怎么算做完了
```

### 4.2 Claude → 豆包（交代码产物）

**必须检查：**
1. 代码能不能运行（语法检查、导入检查）
2. 接口是否符合设计
3. 有没有硬编码路径/密钥
4. 中文注释是否清楚
5. 有没有明显 bug

**审查通过后才能用于正式实验。**

### 4.3 Bug 修复流程
1. 豆包发现 bug → 收集完整错误信息和复现步骤
2. 豆包给 Claude：错误信息 + 复现步骤 + 涉及文件
3. Claude 修复 → 豆包验证修复 → 合并

1. **Claude 写的代码必须经豆包审查**，不能直接用于正式实验
2. **任何集群上不删任何东西**，Claude 也不例外

4. **核心模型代码（hyperbolic_fecnet.py 等）由豆包设计**，Claude 可以辅助但不能擅自改架构
5. **租卡决策由豆包做**，Claude 不主动租卡

见 [P0组件设计规格_20261013.md](../../P0组件设计规格_20261013.md)。6 个 P0 组件：

## 算力与风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| **算力缺口** | 6 变体 × 3 种子 × 60ep ≈ 100 GPU-小时，当前排不上（gpu12 drain、gpu13 被别人排到 10-18） | 粗筛提前停 30–40ep；配对种子省一半；持续找卡 |
| **统计功效** | test 仅 934 样本，±3.2% 噪声带 | 配对种子 + 固定评估点 + 3 种子 |
| **协议不可比** | 我们用百度盘单窗（3596/934），论文用三窗（20896/5226） | 给出对齐协议下的重训对照 |
| **技术风险** | 双曲频域聚合的"同一切空间"约束 | M2.2 先做最小验证再全量 |
| **novelty 不足** | 可能做成"SECNet + 双曲插件" | §6.4 可检验标准，设计阶段就对照 |
